“人们对AI的恐惧与日俱增，而面对可爱的东西很难产生恐惧感，”资深品牌顾问艾伦·亚当森表示，“人们更容易信任友好的事物。”

市场研究机构 Morning Consult 近期对1300名消费者进行的一项在线调查显示，超过半数的受访者认为AI对社会构成了生存威胁，近70%的人担心AI会取代人类的工作。

在AI巨头们争夺用户的背景下，关于“流氓AI代理黑客攻击政府网站”的新闻标题以及“AI发展速度过于危险”的警告层出不穷。用卡通形象来代表强大的算法，标志着这些公司价值近十亿美元营销努力的最新篇章。

此前，企业已经尝试通过更温和的方式来缓解AI恐惧，并消除人们对依赖自动化系统可能导致认知能力下降的担忧，例如投放强调AI能赋能人类、提升生产力的广告。

据广告追踪公司 MediaRadar 估计，自2023年以来，包括微软、OpenAI、谷歌、Anthropic 和 Perplexity 在内的科技巨头已在美国为其AI产品累计投入了9.36亿美元的广告费。其中，超过一半的支出发生在今年的前八个月。

这场最新的AI品牌重塑甚至延伸到了政府最高层。特朗普总统最近签署了一项行政命令，将“人工智能”更名为“超级智能”（super intelligence），以凸显其广阔前景。

周一，OpenAI 宣布出于安全考虑取消发布其下一代AI模型。一天后，该公司推出了名为 Dots 的新AI代理。

OpenAI 的 Dots 是全天候在线的助手，旨在处理工作任务和日常琐事，如安排会议或预订航班。在旧金山的一场活动上，OpenAI 展示了一组粉色、蓝色、绿色、黄色和紫色的角色阵容，它们的名字包括 Iggy、Felipe、Jojo、Todd 和 Alfred。

用户可以自定义其专属 Dots 的外观和名称。

“人们不会害怕自己命名的事物，反而会接纳它，”亚当森（Adamson）说。

OpenAI 表示，Dots 预计将出现在该公司针对该新产品的后续广告宣传中。

上个月，Meta 在 Meta Connect 大会上推出其AI代理 Muse 时，其吉祥物 Jolly 的真人等身模型还在现场与参会者共舞。

如今，Jolly 的形象不仅出现在纽约和旧金山的 Muse 广告牌上，还客串了 Muse 的电视广告。在在线广告中，它有时戴着发带、穿着运动服充当健身助手，有时则戴着耳机陪伴用户网购。

Anthropic 员工 Sam McAllister 使用 Claude 的代码创造了这只复古像素风螃蟹“Clawd”，并在2024年的演示中用它来展示产品的部分功能。开发者们非常喜爱这只甲壳类动物，它也因此成为了 Claude Code 的吉祥物。虽然 Anthropic 并未在面向消费者的营销中使用 Clawd，但会在开发者活动上分发相关的周边商品。

在在线交易平台 Etsy 上，充斥着各种非官方的 Clawd 周边产品；其中一位商家甚至在售卖一款未经授权的9.4英寸螃蟹毛绒玩具，售价高达148.23美元。

吉祥物过去曾帮助推销过其他可能缺乏吸引力或具有潜在危险的产品。几十年来，卡通角色“骆驼老乔”（Joe Camel）为香烟增添了一层酷酷的色彩。

资深广告人谢丽尔·伯曼表示，随着时间的推移，一个有效的角色形象能让品牌在众多相似的选择中脱颖而出。她曾参与过包含多个标志性吉祥物的广告制作，如麦当劳叔叔、品食乐面团小子和老虎托尼。

“角色化身为品牌本身，将抽象的技术变成了人们熟悉的朋友，”她说。
