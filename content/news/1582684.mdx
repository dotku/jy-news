报道指出，三星上一次对其定制Android系统进行如此大规模的革新，还是九代之前One UI刚刚诞生之时。近年来，三星的系统升级愈发可预测，主要表现为界面细节微调，以及AI能力和功能的稳步推进。但One UI 10预计将不再局限于外观和功能层面的更新，而是试图为用户带来新的体验方向。

据称，One UI 10将围绕三项核心变化展开。首先是改变用户使用应用的方式：三星将优先推进“情境流”（Contextual Flow），而非传统的“应用孤岛”（App Silos）。这意味着用户完成基础任务时，不必在不同应用之间反复切换；日历事项、位置信息、通信内容等数据将被有机整合到一个统一视图中。该思路听起来像是现有Now Nudge功能的强化版本。

其次，三星希望降低用户的“认知负担”，减少不必要的点击、隐藏菜单和层级结构。无论用户执行何种任务或查找何种内容，操作流程都应更加流畅，避免出现“死胡同”式的交互路径。

第三项变化聚焦于生态协同。三星据称将进一步改善智能手机、平板电脑和可穿戴设备之间的跨设备任务接续能力，推动Galaxy生态实现更高程度的统一。

AI显然也是这次理念转变的重要部分。随着端侧计算和混合AI处理需求不断增长，三星正面临将相关能力商业化的压力，因为大量算力本身意味着成本。消息人士称，三星可能采用双轨模式：核心的日常AI功能继续免费提供，而需要较高算力的第三方集成、高级处理工具等，则可能被纳入订阅付费体系。

在发布节奏方面，由于上述改动规模较大，三星可能难以赶上Galaxy Z Fold9和Z Flip9的发布时间。因此，One UI 10的世代升级很可能安排在Galaxy S29系列发布时推出，而这恰好也将与One UI诞生十周年相重合。

报道同时提到，三星预计会在正式版发布前较早推出开发者预览版。消息人士还建议用户不要仅仅为了等待One UI 10而推迟硬件升级，因为三星的长期软件支持策略应能保证One UI 10及其功能在近期的Galaxy S系列和折叠屏Z系列旗舰上顺利运行。

目前上述内容仍属爆料，三星尚未官方确认One UI 10的具体设计、功能或发布时间。
