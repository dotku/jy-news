Anthropic公司于6月向美国证券交易委员会（SEC）秘密提交了IPO注册声明草案。根据SEC规定，采用保密流程的公司必须在正式投资者路演开始前15个日历日公开其注册材料。

Anthropic公司没有回应有关其S-1文件提交时间的置评请求。

公开备案将扫清11月上市的关键程序障碍，但具体上市时间仍取决于市场状况和其他因素。至关重要的是，这也将使普通投资者首次了解这家人工智能行业增长最快的公司之一的财务细节和风险。

Anthropic 公司正在斥资数十亿美元用于人工智能基础设施，以训练和运行其 Claude 模型套件。这包括与Google ( GOOG ， GOOGL ) 和亚马逊 ( AMZN ) 合作，以及从 SpaceX 的 Colossus 1 数据中心租用图形处理器 (GPU) 容量。

据《华尔街日报》周二报道，该公司2026年上半年营收为163亿美元，净亏损超过800亿美元。路透社此前报道称，华尔街预计该公司估值可达2万亿美元，融资额最高可达1000亿美元。

据《金融时报》报道，上周，Anthropic 在其旧金山办事处向投资者表示，其第三季度收入攀升至 168 亿美元，高于第二季度的 115 亿美元，并指出该公司经调整后也实现了盈利。

在今年IPO市场竞争日益激烈的背景下，这笔巨额融资显得尤为引人注目。本周早些时候，韩国数据中心提供商Elice在筹集1.51亿美元后，首日股价暴跌32%。英伟达支持的Firmus Grid本月早些时候突然搁置了上市计划，原因是投资者对其拟定的估值持反对意见。此外，还有几家公司以市场状况为由推迟了上市计划。

近几日，上市人工智能相关公司的股价也出现波动，因为投资者对人工智能行业庞大的支出需求变得更加谨慎。尤其是CoreWeave，由于投资者质疑其未来的收入前景与其债务负担之间的关系，该公司受到了密切关注。

这一转变凸显了今年早些时候热情买入人工智能相关公司的投资者们如今变得更加挑剔。

一位知情人士表示，鉴于 Anthropic 的规模巨大，其 IPO 的时机预计也将对未来几周内寻求上市的其他公司产生重大影响。

Anthropic 凭借其 Claude 聊天机器人、流行的 AI 编码工具 Claude Code 和 Claude Cowork，在企业市场站稳了脚跟。

竞争对手 OpenAI 原计划于今年进行 IPO，但现在预计将于 2027 年初上市。
