近日，知名开源游戏启动器 Heroic Games Launcher 的部分开发者启动了一项名为 Xodus 的全新开源项目。该项目旨在将 PC Game Pass 游戏引入 Linux 和 macOS 系统。虽然目前项目仍处于初期开发阶段，但团队的目标是结合 Valve 的 Proton 兼容层以及自定义的反向工程运行时环境，使微软 Xbox 的 PC 游戏及 Game Pass 能在非 Windows 系统上顺利运行。

在此之前，Linux 用户想要体验 Game Pass 游戏的唯一途径是使用 Xbox Cloud 云游戏服务，但这受限于网络延迟和连接质量。如果 Xodus 项目取得成功，在 Linux 平台上原生运行 Game Pass 游戏的体验将有机会媲美目前通过 Steam 和 Proton 运行常规 Windows 游戏的顺畅程度。

项目规划显示，开发团队还打算加入对 Heroic、Lutris 和 Bottles 等第三方启动器的支持。通过 Xodus 下载安装游戏后，玩家还可以将其配置为通过 Steam 进行启动。

据该项目的核心开发者之一 imLinguin 在 Reddit 上的最新回应，团队目前已经成功解决了用户身份验证以及游戏下载的技术难题，下一阶段的重心将转向游戏 SDK 的开发。这意味着虽然目前玩家已能下载游戏文件，但游戏尚无法直接在 Linux 系统中运行。
