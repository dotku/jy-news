相关人员在 GitHub 上公开了代码，并在 X 平台分享了演示结果，称其做法是直接在 M4 的 ANE 上执行完整反向传播和 Transformer 训练 。为了避免训练过程卡死后中断，方案中还使用了 exec() 机制在需要时“重启”进程继续训练 。

报道进一步称，这一过程完全没有写入 NAND 闪存，而是把数据和状态都保留在 RAM 中，从而显著提升速度 。在绕开软件限制后，M4 在 iPad 或 Mac 上可达到约 15.8TFLOPS 的 AI 处理性能，足以进行模型训练，而无需依赖昂贵的独立电脑或高端 NVIDIA GPU 。

这一成果是在 M4 上实现的，因此外界也开始猜测 M5 可能会释放出更强的潜力，但目前尚不能确认同样的方法是否适用于更新一代的 Apple Silicon 。
