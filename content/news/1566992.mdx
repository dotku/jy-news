Valve 工程师 Pierre-Loup Griffais 在接受 Digital Foundry 采访时表示，Valve 已与 AMD 合作完成了 HDMI 2.1 及 FRL（Fixed Rate Link，固定速率链路）支持的相关工作，当前的软件栈已经在 Steam Machine 上启用了 HDMI 2.1 可变刷新率（VRR），不仅适配 FreeSync 显示器，也兼容 HDMI Forum VRR 显示设备。他还透露，后续更新将为 Steam Deck 带来完整的 HDMI 2.1 支持，并在 HDMI 接口上加入通过 DSC（显示流压缩）实现的 4K 240 Hz 输出能力。

在他看来，这一系列特性是 Steam Machine 性能“拼图”中的重要一块，后续即将到来的 FSR 4 画质与性能增强也会与之形成配合。尽管 Steam Machine 目前仍然是一个相对小众的产品，尤其是在现阶段的高价定位之下，但 Valve 围绕硬件和 Linux 版 SteamOS 所做的开发工作，已经在更广泛的 Linux 游戏生态中产生了示范和推动作用。过去，由于授权等方面的限制，Linux 阵营在 HDMI 2.1 支持上长期受限，而 AMD 与 Valve 的合作已经将完整 HDMI 2.1 支持引入了开源 Linux 软件栈，为更多 Linux 硬件平台提供了基础能力。

与此同时，Steam Machine 的市场话题正在从“性能”迅速转向“价格”。这款原本被定位为“相对亲民”的小型机-主机混合设备，在 6 月中旬正式开售时，入门价格却高达 1，049 美元，其定价直接受到当前内存与存储市场危机的影响。在 DRAM 与 NAND 价格持续走高的背景下，Steam Machine 的整机成本被显著抬升，引发了玩家和行业内对其性价比的持续质疑，也让“是否会在未来降价”成为围绕该产品的核心讨论之一。

针对这一问题，Valve 在接受 Digital Foundry 采访时给出了相对谨慎甚至悲观的判断。Steam Machine 项目工程师 Yazan Aldehayyat 与 Pierre-Loup Griffais 均强调，从公司角度来看，“没有理由把硬件长期维持在高价位”，Steam Machine 的存在意义在于成为玩家与游戏之间更紧密连接的载体，“越便宜越好”。不过 Aldehayyat 也坦言，Valve 很难对未来价格走势做出乐观预测，“我们并不认为价格会在短期内明显下调”，并补充说业内其他公司同样发出了类似的预警。

Valve 提到的担忧，指向的是当前以及未来一段时间内仍将延续的内存涨价周期。在近期微软宣布 8 月将全面上调 Xbox 硬件价格时，也将 DRAM 成本上行作为关键原因之一，释放出整个消费电子领域必须为存储与内存成本付出更高代价的信号。在这一大环境下，Steam Machine 想要通过简单的 BOM 优化来实现明显降价的空间有限，Valve 也因此对短期降价前景“并不乐观”。

总体来看，Steam Machine 正在性能与体验层面持续进化：其基于 Linux 的 HDMI 2.1 完整支持、VRR 适配以及未来通过 DSC 实现的 4K 240 Hz 输出，将为高端显示设备用户带来更加完善的主机级体验，也同步反哺了整个 Linux 游戏生态。但在另一个维度上，这台小型主机又清晰地折射出当前 PC 硬件市场的成本结构现实——即便厂商主观上希望“越便宜越好”，在 DRAM 和存储价格持续高企的周期内，想要快速把高价 Steam Machine 拉回到最初设想的“亲民区间”，显然并不现实。
