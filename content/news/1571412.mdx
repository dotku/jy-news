现在，埃隆·马斯克表示，特斯拉将在不久的将来对已经停产的 Model S 和 Model X 采取同样的措施。

特斯拉公开的Roadster档案库详细展示了该公司首款量产车型的全貌。它包含了完整的维修手册和零件手册，就像其他所有特斯拉车型一样。

此外，它还收录了电路图和连接器信息，以及涵盖车辆本身和开创性电池技术的运行原理文档，正是这项技术开启了特斯拉的辉煌篇章。

该档案库还包含电动汽车三项关键系统的研发文档，这三项系统使电动汽车成为可能，包括电池监控板（BMS 的一部分）、车辆显示系统（或信息娱乐系统）和空调控制器。

这些文件包括原理图、组件信息、CAD 文件以及 Roadster 设计过程中创建的其他技术资料。

一个值得注意的区别是，研发文档并非服务文档。最终量产车辆和零部件，以及研发文档中提及的零件或维修程序，很可能与特斯拉实际的服务指南有所不同。

即使存在这种局限性，对于车主、独立维修店、工程师和爱好者，以及在特斯拉成功打造 Model 3 和 Model Y 等大众市场电动汽车之后，希望设计自己的电动汽车的公司来说，这些信息仍然是一座金矿。

Model S 和 Model X 是下一代开源产品。

马斯克没有提供发布日期，也没有具体说明特斯拉计划公开哪些Model S或Model X的资料。他的措辞暗示可能会包含车辆设计文档和软件，但具体范围尚不明确。

如今的Model S和Model X都搭载了特斯拉最新的信息娱乐系统用户界面，而这套软件很可能属于高度机密。因此，我们或许可以期待，2012年款Model S的原始软件会作为资料的一部分包含在内。

此外，还有大量历史资料需要记录。Model S 于 2012 年投产，Model X 于 2015 年投产。这两款车型在其生命周期内都经历了多次重大改进，包括几次重要的硬件升级，以及几乎每年一次的车载信息娱乐系统软件重大更新。

虽然弗里蒙特工厂的生产已经停止，生产线也已转为生产擎天柱人形机器人，但设计文件将有助于保存工程历史，以便在未来几十年内制造替换零件。这意味着这些文件也可能成为用户长期的技术参考资料。
