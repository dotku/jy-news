在这次更新中，Codex 以远程控制中枢的方式出现在 ChatGPT 移动端界面，开发者可以从手机连接到已运行 Codex 的机器，包括笔记本电脑、独立的 Mac mini 或托管的远程开发环境。 一旦连接成功，应用会加载该环境的实时状态，其中包含当前活跃的任务线程、审批记录、插件信息以及项目上下文，确保开发者在移动端也能掌握整体进度。

OpenAI 在官方介绍中强调，这次的 Codex 移动体验并非只针对单一任务的简单远程控制，而是具备完整工作流管理能力。 开发者可以在手机上查看 Codex 的输出结果、审批命令、切换模型、发起新任务，并实时跟踪执行过程中的更新。 如有需要，Codex 还可以将截图、终端输出、代码差异（diff）、测试结果以及审批请求回传到移动应用，让开发者随时进行确认与干预。

由于 Codex 的实际运行仍在原有的本地或远程环境中进行，原有的文件访问能力、凭据与权限配置以及本地开发环境设置都可以保持不变。 为了在移动端与桌面端之间建立安全连接，OpenAI 为这套体验设计了一层安全中继（secure relay），用于在不暴露 Codex 桌面应用到公共互联网的前提下，实现与手机应用之间的通信。 OpenAI 也通过社交媒体表示，很多用户此前已多次提出类似需求，如今这项功能率先以预览形式上线，让开发者能够在手机中发起新任务、审阅输出、控制执行和审批下一步操作，而 Codex 仍持续在笔记本、Mac mini 或开发主机上运行。

除了移动端的更新，OpenAI 还面向企业和团队场景推出了多项 Codex 增强能力。 其中，远程 SSH 功能现已普遍可用，Codex 可以连接到由企业管理的远程机器，在这些环境中使用经批准的依赖项、凭据、安全策略和算力资源执行代码任务。 Codex 桌面应用可以自动从用户的 SSH 配置中发现可用主机，并在这些远程主机上运行项目，从而兼顾集中管理与弹性算力。

在自动化和集成方面，OpenAI 也推出了用于 CI 流水线、发布流程和内部自动化场景的可编程访问令牌（programmatic access tokens）。 此外，Hooks 功能也已全面上线，团队可以借此对 Codex 的输入和行为进行深度定制，例如扫描提示词中是否包含敏感信息或密钥、运行自定义校验逻辑、记录会话日志、创建记忆，或针对特定代码库和目录调整 Codex 的行为策略。

在计费和合规方面，远程 SSH 与 Hooks 将向所有 ChatGPT 套餐开放使用。 可编程访问令牌则仅面向企业版与商业版用户提供，以符合更复杂的企业集成需求。 对于需要遵循医疗隐私法规的客户，OpenAI 表示，在本地环境中使用 Codex 时，符合条件的 ChatGPT 企业版工作区可以实现符合 HIPAA 规范的使用方式。

Codex 在 ChatGPT 移动应用中的集成目前已在 iOS 和 Android 平台以预览形式开始分阶段推送，适用于所有支持地区中包括免费版和 Go 版在内的各类套餐用户。 不过在当前阶段，移动端 Codex 仅能连接运行在 macOS 上的 Codex 桌面应用，Windows 支持尚在开发中，预计将在后续更新中推出。
