新的 DS API 峰谷计价机制：

高峰时段：每周一至周五 09:00~12:00、14:00~18:00 (UTC+0800)

闲时时段：每周一至周五 12:01~13:59、18:01~ 周末 (UTC+0800)

闲时时段：每周六至周日全天均为闲时时段 (UTC+0800)

DS API 峰谷机制价格如下：

DS V4 PRO 闲时价格：百万输入命中缓存 0.15 元、百万输入未命中缓存 4.5 元、百万输出 13.5 元

DS V4 PRO 高峰时段：百万输入命中缓存 0.30 元、百万输入未命中缓存 9.0 元、百万输出 27.0 元

DS V4 Flash 闲时价格：百万输入命中缓存 0.05 元、百万输入未命中缓存 1.5 元、百万输出 4.5 元

DS V4 Flash 高峰时段：百万输入命中缓存 0.10 元、百万输入未命中缓存 3.0 元、百万输出 9.0 元

DS V4 Flash 多模态闲时：百万输入命中缓存 0.05 元、百万输入未命中缓存 1.5 元、百万输出 4.5 元

DS V4 Flash 多模态高峰：百万输入命中缓存 0.10 元、百万输入未命中缓存 3.0 元、百万输出 9.0 元
