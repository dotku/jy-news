这套“开发者优化”的 Windows 11 体验，整合了常用命令行工具、熟悉的 shell、更快的环境搭建流程、Windows 上创建和交互 Linux 容器的内建方式，以及一个新的实验性 Intelligent Terminal。

微软表示，自己已基于开源项目 uutils coreutils 为 Windows 打造了 Coreutils for Windows，这是一套用 Rust 实现、可跨平台运行的 GNU coreutils 重写版本。 该公司称，这些是可在 Windows 原生运行的 Linux 风格命令行工具，方便在 Linux、macOS、WSL、容器和云环境之间切换的开发者继续沿用多年形成的命令与工作流。

在去年 Build 大会上将 Windows Subsystem for Linux（WSL）开源之后，微软这次又把 WSL 更深入地整合进 Windows，并推出新的 WSL containers。 顾名思义，这是一种内建方式，可在 Windows 上创建、运行并交互 Linux 容器；微软还为其提供了命令行界面和 API，开发者甚至可以在原生 Windows 应用中运行 Linux 容器。 该功能预计将在未来几个月进入公开预览。

此外，微软还在现有 Windows Terminal 的基础上，继续打造面向开发者的实验性 Intelligent Terminal。
