深度求索此前从 11 月 1 日起对服务端工具和独立搜索、抓取 API 计费。新计费规则执行约 17 天后，模型自主联网恢复免费机制，开发者直接调用搜索接口则继续按照调用次数进行计费。

旧版搜索抓取计费规则 (11 月 1 日执行)：

搜索请求费用

网页抓取费用

模型处理内容产生的费用

搜索和抓取均按照每 1000 次成功请求 5 元计算，例如某次任务搜索 1 次并读取 3 个网页，工具调用费用为 0.02 元，模型生成答案消耗的 Token 另行计费。11 月 18 日调整后，如果搜索及网页读取由模型的服务端工具触发，这部分 0.02 元工具费取消，只保留基本的 Token 处理费用。

3 类服务端联网方式重新免费 (11 月 18 日执行)：

DeepSeek 联网工具中的网页搜索、图片搜索和阅读链接

Anthropic 兼容 API 中的 web_search，包括 Claude Code Web Search

Responses API 的 web_search

DeepSeek Harness 选择 DeepSeek 旧版搜索提供方时的联网操作

为方便开发者们统计模型在处理任务时的行为，API 响应仍然会通过 server_tool_use 返回搜索和抓取次数，但这些服务端工具调用不再据此扣费，开发者可以直接忽略这部分内容。

独立搜索和抓取接口仍然按次收费：

需要特别说明的是，开发者通过 API 直接调用独立搜索和抓取接口时依然按次进行计费，其中搜索接口需要返回 HTTP 200 且列表非空才会收费，抓取接口则需要成功取得网页正文后才会收费。请求失败、搜索无结果或者抓取超时均不计费。

因此开发者如果只需要模型自行查找和阅读资料，可以改用服务端联网工具降低成本。需要自行控制搜索结果、排序或 RAG 处理流程时，再使用需要付费的独立搜索和抓取接口。
