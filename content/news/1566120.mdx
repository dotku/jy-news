用于支持 Rust 基金会的各类项目：

这笔 60 万美元的赞助款主要用于对 Rust 语言生态系统维护者工作的支持，通过持续支持维护者、技术重点和关键项目来加强 Rust 生态系统，Rust 基金会称 OpenAI 的追加捐赠将支持基金会旗下的众多项目，包括 Rust 项目目标、Rust 创新实验室、为 Rust 生态系统重广泛依赖的项目维护者提供直接、结构化支持的新兴项目。

Rust 基金会称，可持续维护是人工智能系统背后安全可靠的软件基础设施基石，OpenAI 决定加入 Rust 基金会并支持多种 Rust 项目的关键优先事项，充分展示 OpenAI 支持开源领域的决心，这可以帮助 Rust 变得更加完善并造福所有人。

Rust 社区的长期成员、cargo-semver-checks 维护者 Predrag Gruevski 将加入 Rust 基金会董事会，担任 OpenAI 的白金赞助商代表。
