OpenAI 表示，在此前为桌面版 Codex 应用引入“Computer Use（电脑操作）”功能后，团队观察到用户最常见的工作流几乎都发生在浏览器中。此次 Chrome 扩展正是针对这一趋势进行优化，希望让 Codex 在处理各类基于浏览器的工作时更快速、更高效，尤其是那些传统插件或 API 难以覆盖的复杂场景。

官方公布的数据显示，目前 Codex 每周活跃用户已超过 400 万，自今年年初以来增长了约 8 倍。OpenAI 将 Chrome 扩展视作其“让 Codex 更贴近日常工作”战略的一部分，一方面提升对普通用户日常办公、上网操作的辅助能力，另一方面继续保持对开发者群体的专业支持。

用户可以直接通过 Codex 应用中的“Plugins（插件）”菜单安装这款 Chrome 扩展，完成后即可在浏览器中调用 Codex 协助完成各类任务。
