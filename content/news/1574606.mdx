向左滑动

还有人拿它修复 DeepSeek V4 Pro 表现不稳定的问题，整出了 “ 梁神模式 ”。

总之，社区里开发的热情那叫一个热火朝天。

但咱还是稍微泼点冷水，因为上面这些都得稍微折腾一下，要是刚下载好的样子，那和大家想的可能不太一样……

如果说 CodeX，WorkBuddy 这种是自带精装房的四室一厅江景豪宅。

那刚发布的 DeepSeek Harness，就是个彻头彻尾的毛坯房。

常见的客户端没有，命令行界面也没有，只给大家做了个最朴素的网页端。

但也正因如此，它的自由度非常高，特点就是一切都是插件，一切都能自己 DIY。

有同事搞了个插件，甚至把系统自带的提示词都给卸掉了，直接当场宕机……

这种灵活度，属于是下限很低，但上限也很高了。

为了能玩好这个 DeepSeek Harness，世超也是一通测试，给大伙儿准备了一份从入门到入土的 DSH 教程：

>/ 安装

首先最重要的一步是安装，不少人可能都卡在了这一步，因为 GitHub 里，人官方推荐的方式得在命令终端里敲代码。

不过都 2026 年了，这种杂活儿咱统统丢给 AI 就行。

大伙可以直接复制 DSH 的官方网址，然后粘贴到 CodeX、WorkBuddy、TRAE、甚至豆包专业版这些软件里。

告诉它，帮我把这玩意儿装上就行，接下来基本就不用自己折腾了。

装完以后，我们会得到一个本地访问地址，打开之后，就是最基础的 DSH 界面。

然后我们需要搞个 API 接进去，比如 DeepSeek 的 API，就在官网点 API 开放平台，然后充点钱，就能在 API keys 里面新建 API 出来。

把那一大串 key 复制进 DSH 弹出来的初始界面，或者在模型设置里配置好。

接下来，就能选模型，选工作区，配权限，然后让 AI 直接开工了。

第一眼看着 DSH 的界面，你会觉得非常简陋，甚至一时间都不知道从哪儿下手……

不过市面上有现成的模板呐，咱完全可以照着 WorkBuddy、Codex 这种成熟产品的样子，给它来一波精装修。

>/ 插件市场

第一步，可以先装一个专门用来安装其他插件的插件 —— dsh-market。

老规矩，看着麻烦的直接扔给 AI，咱把插件的链接直接丢给 DSH 就行。

安装完重启一下，再打开设置，就能瞅见插件市场了。

看上去其实跟 WorkBuddy 的技能商店差不多，有各种各样组装好的技能包，也有补足 DSH 短板的补丁。

有了这个可视化的界面，想用啥，一搜一点直接齐活儿。

刚才让 DeepSeek 装，又是搜索，又是写脚本的，花了好几分钟才装完，在这儿点下鼠标，等几秒钟就完事儿了。

装上插件市场，咱这毛坯的 DSH 算是入驻装修队儿了。

>/ 预览功能

接下来咱再装个预览功能相关的插件。

因为众所周知，一个成熟的 Harness， 是能够直接在里面查看它生出来的文件的。但 DSH 没这待遇，想看项目文件？得跳转到其他应用里才行。

好在社区里已经火速更新了。

在刚刚装好的插件市场里搜 sidebar，找到这个“DSH-better-sidebar”，直接安装就行。

这样一来，我们就能在 DSH 里面直接看到 Markdown，HTML 这些文件，Markdown 里的文本还能直接编辑。

而且除了预览，它还内置了一堆其他功能，像是看任务进度，感受 Agent 集群吭哧吭哧干活儿的氛围。

或者自带的终端，用起来也比电脑上的更方便，乃至于开发小项目的时候，它甚至还能给你搞个 Git 树，管理不同版本的代码，专业技能这块儿没毛病。

到这一步，DSH 才开始有点成熟 Harness 的样子了。

>/ 连接IM

另外，咱们还可以通过插件让DSH连接微信，飞书，钉钉，让它像龙虾一样融入生产环境。

还是打开插件市场，搜索IM，也就是即时通讯软件，安装这个dsh-im插件，装好刷新一下就能用了。

此时再打开设置，在插件的子菜单中，就能看到IM机器人的选项。

里面打包了飞书，钉钉等应用的接口，生成二维码后扫一下就连上了，相当方便。

>/ 满血DeepSeek V4 Pro

除了加功能，DSH 插件的另一大妙用是打补丁。

因为一切皆插件，所以咱甚至能用插件的方式，改变模型的思维方式，帮 DeepSeek V4 Pro 的性能往上再堆一些。

还记得这个模型发布时褒贬不一的风评吗？

有人仔细的观察了一下 DeepSeek V4 Pro 的思维链，发现了一个挺玄学的现象：

简单点说就是发挥不稳定，如果思维链的起步是 Let me，那这次对话基本上就有点拉；但如果开头变成 We need，那就说明这把稳了，AI 的智商又占领高地了。

所以为了稳定让 DeepSeek 的智商在线，就有大佬做了个插件“dsh-anchored-standard”。

装上后，可以让模型的思维链尽量用 We need 起手，属于强制给 DeepSeek 开机了。

或者装“dsh-web-ui-all”插件，里面预置了个 “ 梁神模式 ”，功能相似，启动后椅子直接瘫坐在原子弹上……

不过这种操作目前多少还是带点玄学成分，真想稳定提升效果，还是得看官方后面的模型优化才更靠谱。

装修到这儿，咱的 DSH 就差不多告别毛坯了。

>/ 桌面客户端

当然，话说回来，如果你实在不习惯网页端，还是更习惯传统的桌面客户端，那也没事儿。

翻翻 GitHub，上面已经有非常多的项目了，都可以把 DSH 给包装成我们所熟悉的样子，下载安装包，安装后就能用了，也不用一直开着终端窗口。

但在我上手试了试后，只能说未来可期，仍需努力。

拿 star 数 1 万多的“deepseek-harness-desktop”来说，启动是方便了，但像装插件之类的操作可能还要更麻烦一些。

因为插件大都是照着网页端开发的，安装命令都不一样。而且一般也不会对某个桌面端做专门适配，即使装上了，也可能出现兼容问题没法儿用。

所以建议大家还是先观望一手，等它们稳定些再来试试。

所以为啥 DSH 官方不开发桌面端呢？

世超又回去翻了翻 DSH 的代码仓库，找着一些蛛丝马迹。

从项目的提交日志来看，DSH 的开发团队规模不大，人力比较有限，要是搞桌面端，那光是 Mac 和 Win 的系统适配就得花很大功夫。

而且 DSH 本身还只是预览版，连这次咱看到的网页端界面，本质上也只是个插件而已，在这种自由生长的理念下，桌面端好像还真急不得。

整体装修完，大伙儿也能感觉到，它跟主流 Harness 还是有差距的。

但它更自由，更好玩儿，你可以像拼乐高一样，拿着社区无限供应的零件，拼出一个最适合你自己的 Harness。

还有那些用不着的鸡肋功能，也能统统扔掉。

而且别忘了，它才发布了一周而已，社区里的大伙儿修 Bug 加功能，已经涌现出了上万个插件。

在这种夸张的热情加持下，毛坯房变精装还真就指日可待……
