随着 Edge 152 版本陆续推出，Edge Drop 已不再提供。尽管 Microsoft Edge 的用户数量不如预期，而且它与 Chrome 一样基于 Chromium 引擎，但这款浏览器仍凭借一些独特功能拥有自己的用户群。这些功能包括符合 Windows 11 设计规范的界面、视频翻译、侧边栏、集合，以及 Edge Drop 等实用工具。

Edge Drop 曾经是很多用户喜欢 Edge 的原因之一。通过 Drop，用户可以在电脑或手机上复制大段文字，并快速将其发送到其他设备。除了文字之外，用户还可以分享截图、图片、视频，甚至是体积较大的文件，例如 ISO 镜像文件。

从功能定位来看，Edge Drop 类似于“给自己发邮件”，但拥有更加完善的界面。用户只需将文件拖入 Drop 窗口，文件便会立即出现在其他已登录同一账号的 Edge 设备上。

所有内容都会以类似聊天记录的时间线形式显示，Edge 还可以在有新内容到达时向其他设备发送通知。微软不会压缩通过 Drop 分享的文件，文件会保存在用户的 OneDrive 中，直到用户手动将其删除。

以 WhatsApp Web 为例，用户通过它分享图片时，图片不一定能够保留原始画质。但 Edge Drop 基于 OneDrive，因此通常不会遇到这一问题。当然，Drop 所使用的空间会计入 OneDrive 的云存储配额，不过用户通常可以使用约 5GB 的免费存储空间。

由于 Drop 是 Edge 内置功能，而不是 Windows 专属工具，因此它并不局限于 Windows 设备。只要用户在 Edge 中登录同一个 Microsoft 账号，就可以从 Windows 电脑发送内容，并在Android、iOS、macOS 或 Linux 设备上接收。

目前市面上并不缺少 Edge Drop 的替代方案。Windows 11 提供“附近共享”，Android设备也有类似功能，用户还可以通过其他方式在手机和电脑之间同步文件。不过，Edge Drop 凭借简单易用以及良好的跨平台体验，仍然具有一定优势。

不少用户一直把 Edge Drop 当作文件分享工具使用。对他们来说，微软移除这一功能令人失望，因为它曾经是促使他们继续使用 Windows 11 默认浏览器的重要理由之一。

微软在版本更新说明中表示：“Drop 已停用。我们正在简化 Microsoft Edge。Drop 已在 Microsoft Edge 152 版本中停用。”

不过，微软这一解释并未让所有人信服。Drop 本身是可选功能，用户可以让它留在菜单中，也可以将其固定到工具栏，并不会强制增加浏览器的复杂程度。相比之下，出现在新标签页、侧边栏和右键菜单中的大量 Copilot 相关功能，反而更容易让 Edge 显得臃肿。

微软在几周前就开始提醒用户 Drop 即将停用，并建议用户在功能消失前下载需要保留的文字笔记。

微软表示，通过 Drop 分享的文件、截图以及其他附件不会被删除，因为这些内容存储在 OneDrive 中。但用户通过 Drop 发送的文字并不会以同样的方式保存在 OneDrive 中，因此微软提供了“下载文本”按钮，允许用户在功能移除前将这些文字导出为 TXT 文件。

如果用户没有提前保存这些文字内容，之后将无法恢复。
