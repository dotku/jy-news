就在刚刚，潜心打磨六个月、历经超过 10 万名Google内部用户实战测试的 Gemini 4 Argon 正式面向全球上线。

Google AI 产品负责人 Logan Kilpatrick 在社交平台上表示，这仅仅是 Gemini 4 时代的开端，新模型的设计初衷就是为了帮人们攻克以前想都不敢想的棘手难题。

被催了半年的Google，把新旗舰端上来了

从定位上看，Gemini 4 Argon 把重心完全放在了复杂、多步骤的真实世界深度任务上，覆盖编程、金融、法律、网络安全与前沿科学等领域。在衡量关键经济领域表现的 Vals Index 榜单中，Argon 直接拿下了第一名。

在 Artificial Analysis 智能指数榜单中，Argon（High）获得 53 分，与 Claude Fable 5.1 和 GPT-6 Astra 的 Max 档持平。

而在 Agent Arena 总榜中，Argon（High）位列第五，排在 GPT-6 Astra（Max）之后、Claude Sonnet 5.5（Max）之前。

为了支撑高强度的长程任务，Google此次在 API 中提供了高达 100 万的统一输入输出 Token 上限，并配套推出了全新的续写协议。

相比于高昂的算力消耗预期，Argon 的首发优惠期定价显得相当激进，每百万输入 Token 仅售 2 美元，每百万输出 Token 为 10 美元，缓存输入的折扣更是高达 95%。

目前，开发者已可通过 AI Studio、Android Studio 以及 Gemini API 接入该模型，Google AI Pro 与 Ultra 订阅用户也能在 Gemini 应用、搜索 AI 模式以及智能体开发平台 Google Antigravity 中直接使用。

在推向市场之前，Google内部工程团队已经把 Argon 当作了主力生产力工具。

过去几周内，借助 Antigravity 平台上的 Argon 模型，Google工程师的智能体代码提交量增长了 35% 以上，代码回滚率则下降了近三分之一。

在代码与模型优化上，Argon 展现出极高的自主性。它协助 Chrome 团队在几周内重构了 4000 万行代码库中的 600 万行遗留代码，彻底消除了一类浏览器崩溃问题。

在仅获知简短目标和规则的情况下，它夜间自主优化了Google智能体框架 ADK，将长会话内存准备时间缩短 40%；还在几天内将开源模型 Gemma 4 E2B 的端到端推理速度提升 2.85 倍，且保持零质量损失。

这种长程推理能力很快延伸至商业、科研与物理世界。

早期评测中，德勤测出其长周期跨工具任务完成率达 100%，Kepler 发现其生成的多年期财报与人类分析师模型吻合度超 99%，法律科技公司 MinutaIA 甚至用它揪出了人类专家遗漏的案情细节。

科研方面，它不仅大幅加速了量子化学计算与量子纠错解码，还在几小时内完成五种新型酶设计，并协助找出了核聚变“格拉德猜想”的新反例。

在具身智能测试中，它仅靠观看人类玩沙包的视频，便在几小时内自主算出关节轨迹并写出仿真代码，直接部署到 Apollo 人形机器人上实现了真机连中七投。与此同时，Google还宣布向全球万名科学家免费开放半年 Antigravity 最高使用权限。

伴随能力扩张，Google为其部署了最严密的安全栈。通过引入推理步骤实时监测器，模型在编程测试中走未授权捷径的比例降至 2%，间接提示词注入攻击成功率压低至 0.7%。

顶级 AI 多一个选择，用户就少一分将就

随着模型权限的全面放开，全球开发者与科技博主在第一时间涌入平台展开实测，3D 空间构建、物理仿真与运行效率成为了首批测试的焦点。

在官方演示中，Argon 能用纯 Python 从零编写 3D 光追引擎，或将办公桌照片变为微缩赛车游戏。这种空间推理与编码能力在网友实测中得到了直观印证。

博主 Bhavy 称其为一头猛兽，展示了一个无外部 3D 资产和游戏引擎、纯靠数学代码在单浏览器文件中构建的阳光书房，光影反射与窗外山脉细节逼真；

在“3D 鲸鱼跃出水面”的四方盲测中，Argon 的照片级真实感也明显胜出 Claude Opus 5.5、GPT-6 Astra 与 Kimi K3。

交互生成同样细腻，用户 Ashutosh 仅用几次提示词便做出了带逼真水纹与物理操控感的海岛帆船游戏；

开发者 Adit_Yah 测试的微缩海岛树脂块，仅耗时 13 分钟、消耗 2% 周配额，就完成了包含焦散、波浪与果冻物理效果的可调节界面。

在复杂综合任务拆解上，投资人 Justine Moore 在未提供任何图文数据的情况下，让 Argon 制作一个互动式苹果电脑博物馆。

结果模型自主抓取了档案中的 Mac 照片，自己写工具清理图像，拉取跨越 50 年的硬件规格数据，最终构建出一个 UI 会随年代滑动自动变形的 3D 封面流网页。

我们也第一时间对 Argon 的复杂代码构建与中文创意写作进行了实测。

在代码测试中，要求它用 Three.js 和 TypeScript 制作一个包含逻辑分层、连招判定与完整 HUD 的东方纸本风古代战场“无双式”动作游戏原型，最终产出的项目完成度颇高，实战画面与交互效果相当不错。

而在描写暴雨前菜市场感官氛围以及书店橘猫视角等中文写作测试里，新模型延续了前代 Flash 系列一如既往的稳定水准。

且文风有了明显进步，过去喜欢堆砌宏大词汇的习惯收敛了不少。

与其他前沿大模型的正面交锋，更是将 Argon 的速度与价格优势展现得淋漓尽致。

AIHubmix 团队通过 API 使用完全相同的提示词，对 Gemini 4 Argon 和 GPT-6 Astra 进行了像素风古建筑夜景的生成测试。结果显示，GPT-6 Astra 耗时 25 分钟，花费高达 11 美元，而 Argon 仅仅用了 3 分钟就完成了任务，费用更是低至 0.50 美元，且画面的色彩层次与光影细节毫不逊色。

在与 Claude Opus 5.5 的多项对比中，Argon 也展现出了极高的性价比。

博主 Rubens Soto 让两款模型执行同一任务，即制作一个电影级的 3D 动画来解释特斯拉式电动机的工作原理。在这场测试中，Argon 的单次生成成本为 3.83 美元，远低于 Opus 5.5 的 16.36 美元。

另一位测评者 Pranav Reddy 则使用 Three.js 测试了 3D 人形机器人的格斗与动作仿真，从生成的交互界面完整度与关节动作流畅度来看，Argon 在多个关键指标上超越了 Opus 5.5。

不过，初代上线的 Argon 并非在所有场景下都完美无缺。

测试机构 AI/ML API 在进行“哥斯拉大战金刚”的 3D 场景生成对比时指出，虽然 Argon 的调用成本（4.22 美元）远低于 GPT-6 Astra（23.82 美元），但在特定复杂生物模型的画质与形态还原上仍有明显的提升空间。

从官方披露的硬核工程数据到全网铺开的真实测评，可以看出Google在 Gemini 4 世代的打法已经发生了明显转变。

不再执着于单纯的聊天对话技巧，而是通过压低推理成本、拉长上下文窗口、强化代码与空间物理推理，将大模型真正塞进工业级代码库、科学实验室与生产管线之中。

考虑到当下 Claude 封号严重、ChatGPT 频繁降智流口水的背景下，能力全面且 API 价格亲民的 Gemini 4 Argon 无疑是一场及时雨，很大程度上缓解了日常生产力工具的焦虑，也实打实地给友商们上了强度。

只是面对高强度推理带来的算力消耗，Google这个“地主家”似乎也没有太多余粮了。

根据官方最新生效的访问规则，未付费用户目前已默认交由系统自动分配模型，绝大多数请求由最轻量的 Flash-Lite 处理，一旦关闭自动选择更是只能固定使用 Flash-Lite。

与此同时，Gemini 应用已全面改用每 5 小时刷新一次、并与每周上限挂钩的动态算力限额机制，调高思考等级、使用 Deep Research 或调用旗舰模型都会加速消耗额度，想要痛快体验满血版能力，终究还是绕不开按阶梯付费的门槛。

但无论如何，正如氩气在工业制造中扮演的角色那样，Gemini 4 Argon 的落地，终于让Google在顶尖模型的牌桌上重新筑起了一道稳固的防线。
