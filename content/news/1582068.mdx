尽管 Azure 的收入增长正在加速，但微软仍进行了上述成本削减讨论，这凸显了数据中心支出给公司财务带来的沉重负担。

知情人士表示，该公司尚未敲定任何削减成本的措施，相关计划仍可能发生变动。·巴布拉尼仅负责 Azure 内部的一个部门，而整个云业务部门总共拥有约 6 万名员工。·巴布拉尼所在的部门负责开发云服务器业务相关的软件，并不属于 Azure 数据中心团队。

微软发言人在一份声明中表示：“Azure 领导层并未指示团队制定削减成本的计划。任何负责任的公司都会针对各种市场动态及情境（无论是积极的还是消极的）做好准备。这种报道既不准确，也缺乏严谨性。”

据知情人士透露，为了削减部分成本，微软可能会裁减云业务部门的外部承包商。

近几个月来，Azure 部门的一些高管私下指出，除了高昂的数据中心开支外，人才留用成本也是导致可能进行裁员的另一个原因。据知情人士称，随着 Anthropic 和 Meta 等微软在人工智能领域的竞争对手纷纷招募或试图挖角微软员工，微软不得不采取措施应对这些竞争性薪酬待遇。

据知情人士透露，随着公司实现更多任务的自动化，Azure 负责人斯科特·古思里（Scott Guthrie）也表达了增加现有员工人工智能（AI）相关预算的意愿。近几个月来，微软一直在增加人均 AI 投入，并鼓励员工在销售和软件开发等领域利用 AI 提高生产力。在经历了数轮裁员和自愿离职计划后，截至 6 月，微软的员工总数较一年前略有下降。

尽管甲骨文和亚马逊AWS等其他主要云服务商在AI数据中心方面的资本支出增加，导致各自的自由现金流受到冲击，但它们在努力提振营收增长的同时，也采取了包括裁员在内的削减成本措施。

微软内部的这些讨论正值公司围绕高管阿伦・乌拉格（Arun Ulag）重组云业务部门之际。近几个月，多名资深老高管缩减职责或退休，微软CEO官萨蒂亚・纳德拉提拔了一小批新生代管理者，乌拉格便是其中之一。知情人士透露，此前负责 Azure 数据库产品的乌拉格，现在还将统管 Azure 核心业务（Azure Core）的一众高管。Azure Core 为 OpenAI 等客户提供算力。这批高管包括巴布拉尼（Bablani）、比利・安德斯（Billy Anders）、道格拉斯・菲利普斯（Douglas Phillips）以及马克・鲁西诺维奇（Mark Russinovich）。

面对 Anthropic、Meta 等微软 AI 竞争对手挖角（或试图挖角）自家员工的情况，微软不得不拿出应对方案，抗衡这类竞品开出的优厚聘用条件。

Azure 负责人斯科特·古思里于周一在公司内部宣布了本次架构调整，他表示乌拉格仍向自己汇报。

了解这次重组内情的人士透露，查理・贝尔（Charlie Bell）今年早些时候卸任微软安全业务负责人、转为顾问岗位，如今他将加入乌拉格的管理团队，但依旧直接向首席执行官萨提亚・纳德拉汇报。这也进一步体现出乌拉格在 Azure 体系内地位的上升。

长期以来，Azure 一直是该公司关键的增长引擎，但微软直到上个月才开始以具体金额公布该部门的营收数据。数据显示，在截至6月的12个月里，Azure 创造了1019亿美元的营收，同比增长40%；仅在6月当季，其营收就增长了43%。相比之下，AWS 在同期的全年营收接近1500亿美元，其中包括今年第二季度37%的增长。

尽管 Azure 40% 的营收增长表现亮眼，但据报道，该部门也受到了微软去年初决定暂停一系列数据中心项目这一举措的负面影响。即便如此，该部门目前的营收已占微软总营收的约31%。

与此同时，对人工智能（AI）数据中心的投入也对其现金流产生了一定压力。该公司在6月当季产生的自由现金流为200亿美元，虽较第一季度增加了40多亿美元，但与去年同期（即去年第二季度）相比则下降了20%。
