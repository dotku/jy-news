下载离线安装文件：

更新编号：KB5101684

更新类型：非安全预览更新 (带有测试性质)

构建版本：Windows 11 Build 26100/26200.8973

适用版本：Windows 11 24H2/25H2 版

适用通道：Stable / 正式版

发布日期：2026-07-28

下载地址：https://catalog.update.microsoft.com/Search.aspx?q=KB5101684

部分亮点变更如下：

1. 资源管理器现在可以自动按适当的单位显示文件大小，例如 KB、MB、GB、TB 等。

2. 本次更新已经修复资源管理器首页加载时可能出现的灰色闪烁和意外滚动到顶部的问题。

3. 本次更新改进应用搜索功能，在查找已安装应用时可以更好地处理拼写错误和不完整的应用名称。

4. Windows Hello 增强型登录安全性现已支持外置指纹传感器，需 USB 指纹传感器支持 ESS。

5. 本次更新已提高电源设置的可靠性，即设置后会应用到所有电源计划，包括显示 / 睡眠 / 休眠 / 合盖等。

6. 本次更新包括对更新本身清理逻辑的更改，这样在安装更新后可以立即提高性能，而不是拖慢系统性能。

其他部分变更：

1. 提高在某些场景下 DHCP 续订的可靠性，尤其是在收到来自 DHCP 服务器的 NACK 时。

2. 本次更新提高 IPP 互联网安全打印协议打印机的打印速度 (每分钟可打印页数)。

3. 本次更新提高资源管理器的可靠性，包括打开跳转列表和最近使用的文件、共享文件、文件夹等。

4. 本次更新还提高登录和锁屏界面的稳定性，尤其是在系统内存不足的情况下。
