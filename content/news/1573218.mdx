近日，据 Steam Deck HQ 报道，这一猜测得到了进一步的印证。一名 Epic Games 员工在 Discord 的问答活动中向成员透露，Linux 版本的启动器目前正在开发中，并且“很快”就会发布。虽然该员工并未给出具体的发布时间表或说明原生 Linux 版本的当前进度，但这无疑证实了 Epic Games 正在积极推进 Linux 平台的支持工作。这同时也表明，尽管 Epic 首席执行官 Tim Sweeney 先前曾对 Linux 发表过轻视言论，但公司现在正开始更加重视 Linux 作为一个游戏平台的潜力。

此外，该名 Epic 员工还暗示，Linux 版的 Epic Games 启动器将具备专为该平台定制的调整与功能。他评论道：“我们需要做的不仅仅是提供一个能在 Linux 上原生运行的启动器版本。”虽然他没有详细说明具体会包含哪些内容，但外界合理推测，这可能涉及提供一种以上的打包格式（例如对完善 Steam Deck 支持至关重要的 Flatpak），以及用于管理兼容层的工具。未来甚至可能还会加入控制台视图，并实现与 Steam 客户端的自动集成，从而更好地匹配 Steam Machine 和 Steam Deck 等硬件设备。
