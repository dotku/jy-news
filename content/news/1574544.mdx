家人证实史蒂夫已因病离世：

尽管距离史蒂夫离开内核维护岗位的时间非常短，但非常令人痛心的是，目前史蒂夫家人已经证实史蒂夫因病离世。现在在 Linux Kernel 中 CIFS/SMB3 的主要维护者已经变更为保罗・阿尔坎塔拉和全南宰，这两名工程师将共同维护内核中的 CIFS 和 SMB3。

史蒂夫的主要工作：

史蒂夫曾长期在 IBM 公司担任工程师，在 2018 年史蒂夫加盟微软并负责 Microsoft Azure 存储项目，同时史蒂夫继续担任 Linux Kernel CIFS 内核代码的上游维护者，近期史蒂夫还在负责 KSMBD 项目，这是内核中新的 SMB 服务器实现。

在自我介绍中，史蒂夫称自己的研究兴趣主要集中在网络互操作性、文件系统以及现代高性能网络文件系统。从 1989 年开始史蒂夫就从事网络与文件系统的开发与设计工作，在 IBM 时史蒂夫担任 IBM Linux 技术中心的文件系统和网络文件系统架构师。加盟微软后，史蒂夫成为 Microsoft Azure 存储团队的首席软件工程师，主要工作包包括改进 Linux 对 SMB3 服务器的访问。
