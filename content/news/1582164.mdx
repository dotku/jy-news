“谢谢 REA，我的 HP 打印机终于能用第三方墨盒了！”

如果说 2026 年上半年 GitHub 上最火的项目是龙虾 OpenClaw。

那么下半年这个头衔应该属于 REA，一个逆向 MCP。

REA 的仓库其实 4 月就建好了，不温不火地更新了半年。直到 10 月 7 号前后突然爆了，登上 GitHub 热榜第一。截至我写稿时，它已经有 22.3 万颗星，在 GitHub 有史以来的星数排行里排到第 23 位。

看到这儿，可能有差友好奇：到底什么是逆向，逆向又能帮我们做什么？

别急，马上你就知道了。

去年，我给大家推荐过一个网页版红警。

这是一位罗马尼亚开发者为了让大家打开网页就能玩红警做的项目。由于没有源代码，他只能照着《红警 2》的录屏一帧帧去推算、还原游戏逻辑，手搓了 5 年代码。

这种呢叫复刻，也叫黑盒重写。

那逆向呢，是把软件、游戏的安装包拆开，还原内部逻辑，看看它的代码到底是怎么写的。

比如从 Notion 复制一段内容再粘回 Notion，还是原来一样的格式。这怎么做到的？

你用 REA 拆开 Notion 就能发现，它是在剪贴板的 HTML 里夹了一个编号，粘贴时编号对上，才从本地把整块内容还原回来。

如果还不太明白，差评君打个比方。

复刻就相当于你来杭州吃了一盘西湖醋鱼，“哎妈呀咋这么好吃”。回家后，你通过回忆和舌尖那一抹残香，给父老乡亲还原了西湖醋鱼。

但如果你是偷溜进厨房，瞄了几眼大厨手法，还抄了食谱——恭喜你，逆向了西湖醋鱼。

一个 cosplay，一个进入体内。

好，知道了逆向是啥，那具体怎么逆向呢？

逆向常用的手段，一个是抓包，把 App 和服务器之间传的数据截下来看；另一个是反编译，把编译好的程序还原成接近源码、人能读懂的代码。

以前这是安全研究员和破解组的手艺，得会用Ghidra、IDA这类专业工具，还得读得懂汇编，差评君这种看见汇编就头大的人想都别想。

但这次，REA 把这些工具打包成 MCP，接到了 Codex、Claude Code 这类 AI 编程工具上。

装好之后，你只要和 AI 说一句「用 REA 帮我看看这个 App 是怎么做的」，AI 就会自己去拆解了。

那把 App 逆向拆开了，咱们能干啥？

大致能干两类事：一类是把藏在厂商 App 里的功能，挪到自己顺手的地方；另一类是绕开厂商故意设下的限制。

比如网友@JiJiJi03住在老小区，门禁对讲机早坏了，前几年换了新门禁，能用手机 App 开门，可每次外卖小哥打电话，他都得放下手头的事去翻 App。

他就想，能不能把开门放到更顺手的地方？可这个开门 App 是用 Flutter 写的，他用尽毕生所学，发现靠普通的抓包工具根本抓不到接口。

前几天，他让 Codex 用 REA 分析这个 App 的 APK 安装包，看看登录机制是怎么实现的。很快，GPT-6.1 就把 App 反汇编了一遍，找出了负责登录、接口和加密的那几个文件。

图源推特@JiJiJi03

摸清接口后，他就把开锁功能集成进了自己写的家庭屏 App，装到闲置安卓机上。

好了，现在他伸手就能开门了。

图源推特@JiJiJi03

开头那两个网友也是类似。

一个懒得找遥控器，把自家空调做进了 Mac 的菜单栏；

一个和 Codex 一起，用 REA 逆向了马桶的微信小程序，摸清蓝牙协议，半小时就在电脑上做出了一个遥控器，点一下，马桶盖真的翻开了。

虽然我不太理解用电脑控制马桶的爽点在哪。。。

至于逆向打印机的那位网友，就属于第二类。

众所周知，天下人苦惠普打印机久矣。它靠一套叫动态安全的机制，通过固件更新识别并屏蔽第三方墨盒，逼大家只能买原装。

难怪那位网友要专门发帖谢谢 REA。

感觉生活一下变美好了没有？我们掏钱买的那些设备，好像真的属于我们自己的了。。。

别急着兴奋，这还是开胃菜。借着 REA 的热度，接下来一定会有更多新鲜、冷门的玩法被挖掘出来。

为啥这么说。

昨晚差评君在家也试了下 REA。我想把米家的电饭煲、洗碗机、小爱音箱，石头的扫地机，绿城生活里的水电费，全部搬到 Mac 的菜单栏上，不然一家一个 APP 是真烦。

大概 1 小时吧，Claude Code 把 App 做出来了一半（因为涉及安全被 Claude 强行打断并警告）。

但我看了下操作记录，这次 REA 干的活不多。米家、石头这种大牌，从 2017 年起就被社区高手一点点逆向透了，现成的开源项目拿来就能用，REA 只是帮忙验了验货。

但你发现重点没有：

正因为米家、石头用的人多，才值得高手们前赴后继地逆向。

可一个小区的门禁、一款马桶的小程序呢？谁来帮你逆向？

REA 改变的就是这一点：再冷门的产品也能被拆开，每个人都有机会用逆向解决自己的问题。

我有个朋友叫艾洛，在一所中学的信息处当老师。学校每天的打铃、听力考试放音，都靠一套数字广播系统。哪个年级考试，他就得手动调那片区域的几十个铃声，免得上下课铃吵到考生，第二天再改回来。

这听着就觉得麻烦对吧？

但没办法，人系统早停更了，问厂商要二次开发文档更不可能，换一套又要十几万。

REA 爆火之后，艾洛也用AI逆向了这套系统的 WebSocket 接口，重写了一个控制面板。

现在好了，只要他输入考试日期、区域和科目，对应区域里影响考试的铃声就会全部自动静音。

技术平权了啊，兄弟们。

照这个势头，那些厂商早已停止支持、甚至厂商都没了的老设备、老软件、老游戏，都有机会焕发新生。

比如有网友多年前买过一款 Mac 日历 App，作者早就不更新了，在新版 macOS 上开始出毛病。前几天他用 REA 把它拆开，花两个半小时重做出一个功能几乎完全还原的版本。

图源推特@李不凯正在研究

写到这里，一切似乎都很美好，是吧？

可逆向，真的只有美好吗？

和艾洛聊完，我们都觉得这里面更多的是危机。用他的话说：我们正处于一个属于AI的武侠时代。

武侠的表象是江湖儿女快意恩仇，本质却是侠以武犯禁。

当AI帮我们模糊了技术壁垒的界线，那么下一步模糊的必然就是道德底线。

差评君前面写的那些，大家之所以看得爽，是因为我们在挑战商业巨头。“妈的我买的设备并不完全属于我，这个权限没有，那也不能碰。”逆向，帮我们完成了单枪匹马挑战巨头的故事。

可巨头就一定是反派吗？

就像《我不是药神》里，药企要回本，病人要活命，谁都没错。软件世界也一样：厂商要赚钱，用户想拿回自己花钱买的东西。

两边都没错，矛盾又调和不了，这么多年却一直没彻底爆发，中间一定有一块灰色地带在泄压。

在药神里，这块地带是药贩子；在软件世界里，它就是逆向。

这么多年来，这块灰色地带一直都存在我们身边，只是以前门槛很高，只有少数高手进得去，普通人顶多捡点他们留下的现成工具。

REA 干的事，就是把这块灰色地带直接铺到了每个普通人脚下。

而灰色地带之所以是灰色，是因为往左走一步是天堂，往右走一步就是地狱。

药贩子做善事，是程勇；做恶，就是卖假药的张长林。

逆向也一样：拿来开门、开空调、给考场的铃声静音，这叫数字平权；可往右走一步，就是版权灾难。

当很多人开始往右边走那一步时，最先踩死的不是巨头，是小团队。

你逆向了大公司的产品，充其量也只能当个玩具。你不可能用逆向的成果来盈利，不然等着吃律师函。

可小团队的产品被人复刻、逆向，早就屡见不鲜。

世超给大家推荐过的不少软件，没几天就会冒出复刻版。比如 NoFeed，出了没两天，其他平台上就冒出来一堆。

大家呕心沥血几个月的产品，别人照着做只要几小时。游戏开发者 Freya Holmér 今年 3 月刚发了一段原型视频，几天之内，应用商店里就冒出了好几款用 AI 照着做的仿品，抢在了她前面。

以前别人只能照着外表复刻，具体怎么实现还得琢磨下。

现在看上别人 App ，就用 REA 深入到二进制层面，逆向它是怎么实现的，然后做成自己的 App 或者干脆破解掉。

这类抄法，很多在法律上一时还说不清。可没有法律以前，杀人也不算犯罪，但不代表杀人没错。

REA 的来临相当于给每个幼儿园的孩子都发了一把 AK47，每个人攻击力极强， 防御力为 0。

当我们把一个几乎必然会滑坡的道德选择摆在大多数人面前，我们真的有考验人性的勇气吗？大家都是往左，还是往右走呢？

所以接下来会怎么样？我不敢说。

差评君只能猜测，大公司会先筑墙：你拿枪，我举盾。把核心逻辑都搬到服务器上，逆向只能看到返回的结果，看不到中间是怎么算的。

独立团队是真不知道怎么办好，这是最好的时代，也是最坏的时代。

但艾洛觉得，真走到 AI 和 AI 没完没了地攻防那一步，是时代的悲哀，那些算力本可以拿去做更有意义的事。

他更相信剧情会和药神差不多：滑坡大面积出现的时候，政府一定会介入，法律会被迫加速更新。

其实这些事咱们 80、90 后也都经历过一次。

大家还记得那段疯狂的网络盗版时代，书、歌、游戏，几乎什么都能免费下载。后来版权收紧，2015 年 7 月，各家音乐平台按要求下架了 220 多万首没授权的歌；再后来，大家开始给音乐 App 充会员，在电子书城买正版。

当然，靠法律解决所有道德问题本来就不现实。法律能兜住底线就够了，这个世界总归还是能缝缝补补地往前走。

只是在缝补完整之前，我们会在 REA 热度中不断地踏入这个灰色地带。有人决定往左，有人选择往右；有人让技术更平权，有人践踏原创。世界在变得更美好，同时也正在更灰暗。

但人类的进度条已经走到此了，这是 AI 发展的必然，是时代的必经之路，是我们每个人都将经历的故事。

此时我也只能和所有人一样，兴奋地，也不安地喊出一句：

欢迎来到，大逆向时代。
