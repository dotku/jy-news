Windows 95于1995年上市后迅速引爆市场。微软在发售后的前四天便卖出100万套，五周内销量达到700万套。为配合产品发布，微软还邀请美国著名脱口秀主持人杰伊·莱诺在雷德蒙德园区主持活动，并在广告中使用滚石乐队的《Start Me Up》。据报道，微软为这首歌支付的授权费用约为300万美元，当时外界流传的1200万美元传闻，也进一步放大了发布活动的热度。线下零售店外，消费者甚至会在午夜排队购买软盘版系统，这种热闹程度在当时颇为罕见。

Windows 95光盘所附内容包括Weezer的《Buddy Holly》音乐视频、Edie Brickell的《Good Times》、电影《罗伯·罗伊》预告片、动画师比尔·普林顿制作的动画，以及弹球游戏和名为Hover!的气垫船游戏。值得一提的是，由于部分微软员工认为该游戏的操作体验较差，私下还把它戏称为“Hoover!”。

将《Buddy Holly》视频收入Windows 95光盘，并不是一件简单的事。陈在今年早些时候的一篇文章中透露，微软当年是直接与Weezer所属唱片公司Geffen Records谈判版权授权，据称并未征询乐队成员的意见。Weezer成员最初得知消息时颇为不满，但后来认为，这次合作成了乐队发展过程中的重要机会之一。在尚无YouTube等在线视频平台的年代，这段视频借助数百万台Windows 95电脑获得了极高的曝光度。

版权问题也不止涉及音乐本身。《Buddy Holly》视频复刻了美国情景喜剧《欢乐时光》中的餐馆场景，并穿插了剧集演员的真实片段。陈表示，微软律师当时不得不逐一联系剧中演员，以取得肖像使用许可；对这名律师而言，追踪联系方式、甚至有机会联系到亨利·温克勒本人，也成了一项颇具趣味的工作。

微软当时对于“好玩”的执着也体现在更多细节上。陈提到，第一套Windows娱乐包的包装盒已经印刷完成时，俄罗斯方块的授权交易尚未最终敲定。微软选择提前赌一把，先印好写有“现已包含Windows版俄罗斯方块”的红色贴纸，待协议正式落地后再贴到包装上。

就连系统中不太起眼的图标资源也带着这种气质。Windows 95内置的pifmgr.dll文件收录了一套可供用户自定义快捷方式的图标，其中包括沙滩球、巫师帽、骰子、兔子，以及一个左侧被咬了一口的苹果图案，与苹果公司的标志方向正好相反。陈确认，这些图标的存在没有特殊功能目的，纯粹是为了增添趣味；至于苹果图案是否另有所指，他并未作出说明。

Windows 95之所以能承载这些内容，也与其对PC体验的改变有关。在它之前，个人电脑往往更像处理文档和表格的工具。声卡、显卡通常属于发烧友或游戏玩家才会添置的可选硬件；安装软件时，用户还可能需要手动修改配置文件，以解决不同设备之间的冲突。同期的苹果电脑和Amiga平台在音视频体验方面更为成熟，但定位专业市场，价格也相对高昂。

Windows 95改变的并非只是硬件价格，而是系统的基础要求。搭载Windows 95的电脑开始普遍配备音频支持、扬声器和CD-ROM光驱；即插即用功能则让硬件能够自动向操作系统识别自身信息，显著减少了手动配置的麻烦。由此，价格相对低廉的Windows 95电脑也能开箱播放音乐和视频，这在当时的主流PC市场中具有重要意义。

彼时，大约80%的个人电脑仍在运行更早版本的Windows或纯MS-DOS，微软拥有庞大的潜在升级用户群。Windows 95将多媒体能力纳入普及型PC的标准体验，在价格和功能之间建立了新的平衡，也成为上世纪90年代后半段PC市场快速扩张的重要推动因素之一。

相比之下，近年的Windows似乎较少呈现类似的“人情味”。Windows 10仍保留了一些让人留下印象的设计，例如默认锁屏壁纸所拍摄的新西兰Wharariki海滩，在系统发布十年后仍因用户辨认出取景地而再度走红。Windows 95的启动音效同样具有这种辨识度——微软当年要求伊诺在短短几秒内营造出鼓舞人心、富有未来感且带有情绪色彩的声音。

Windows 11或许正在尝试找回一部分个性。此前有消息称，随着原启动音效设计师重返团队，微软可能计划刷新系统提示音，这至少表明公司仍有意为产品增加更具辨识度的声音设计。

但在更多层面上，Windows 11给人的印象仍是一套以完成任务为首要目标的系统。微软近期曝光的一项内部项目“Project Aion”，据称以Copilot聊天框为核心，移除了开始菜单、桌面等传统界面元素，更强调以对话方式完成工作，而非提供具备鲜明个性的操作环境。

从效率角度看，Windows 95光盘里的音乐视频、动画和游戏无法提升电子表格处理能力，也无法消除DOS兼容性带来的麻烦。但正是这些看似“无用”的内容，让系统显得不只是由功能和指标堆砌而成的产品，而更像是由一群愿意表达趣味的人创造出来的作品。31年后，如何让Windows重新具备这种令人愿意亲近和记住的个性，或许仍是微软尚未解决的问题。
