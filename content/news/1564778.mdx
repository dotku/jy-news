在多次优化开始菜单、任务栏等界面元素之后，微软一直未对右键菜单进行根本性调整，这也成为 Windows 11 设计中最具争议的部分之一。如今，微软终于确认将着手解决这一问题。微软 Windows 设计与研究负责人 Marcus Ash 近日在 X（原Twitter）上回复用户时表示，团队正在针对 Windows 11 的右键菜单进行改进。

根据 Marcus Ash 的说法，新的右键菜单将重点围绕三大方向：其一是“更快”，也就是提升调用与展开的性能和流畅度；其二是“默认更简洁”，在保证核心功能可达的前提下，减少冗余信息和视觉负担；其三则是“可根据你最常用的操作进行配置”。不过，目前尚不清楚所谓“可配置”将以何种形式呈现，例如是否会提供图形化配置界面，或者支持按照使用频率自动调整菜单布局。

此外，微软也未明确说明传统的“经典菜单”是否会与现代菜单并行保留，还是会被新的方案统一取代。Marcus Ash 仅表示，将“很快分享我们的具体方案”，这意味着详细设计和交互形式可能会在后续的预览版本中逐步揭晓。

按照以往节奏，经过改造的右键菜单预计会优先登陆 Windows 11 的预览版本，首先向实验频道（Experimental Channel）推送，供测试者体验和反馈。在正式方案落地之前，有需求的用户可以通过第三方工具临时改善当前体验，例如 Neowin 推荐的一款名为“Windows 11 Context Menu Manager”的小工具，可用于禁用不需要的菜单项目，从而在一定程度上减轻右键菜单的杂乱感，并提升打开速度。

过去一段时间里，微软已经对 Windows 11 的开始菜单和任务栏做出多项调整，包括增加更多自定义选项、改善布局和交互逻辑等。在这些改动基础上，右键菜单的系统级改造被视为回应用户反馈的关键一步。Neowin 也提醒用户关注后续每周通常在周五发布的 Windows 11 预览构建版本，以获取关于右键菜单改进的最新进展。
