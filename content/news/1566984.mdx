作为本次更新的重心，GPT‑5.6 Sol 被 OpenAI 定位为迄今为止最强大的模型，在代码、生命科学与网络安全等多项“代理式”（agentic）能力上都有明显强化。Sol 新增“max”级推理强度选项，并引入“ultra”模式，可通过内部子代理协作处理更复杂的任务场景，面向高风险行业以及复杂系统环境下的自动化工作流。

在安全层面，OpenAI 强调 GPT‑5.6 Sol 搭载了迄今最为“稳健”的安全防护体系，对高风险活动、敏感网络安全请求以及潜在滥用场景进行了重点防护。OpenAI 表示，该模型已经过针对现实攻击场景的强化测试，目标是在尽量为防御方、合规安全团队和开发者提供实质性帮助的同时，限制其在进攻性用途上的可利用空间。官方介绍称，相比执行端到端攻击，GPT‑5.6 Sol 更擅长帮助用户发现并修复系统漏洞。

值得注意的是，本次 GPT‑5.6 系列的发布受到美国特朗普政府的行政干预，目前并未面向所有用户全面开放。根据 OpenAI 的说法，公司已经同意在现阶段暂缓向大众放开 GPT‑5.6 的完整访问权限，仅向一小部分“受信任合作伙伴”和机构提供 API 与 Codex 形式的访问通道。OpenAI 表示，在完成更多测试之后，才会考虑在 ChatGPT、Codex 以及公共 API 中更广泛地引入 GPT‑5.6 系列模型，时间表则用“即将推出”予以概括。

在官方声明中，OpenAI 罕见地公开对现行政府审核流程表达保留意见，认为这类政府主导的准入机制不应成为未来 AI 模型发布的长期常态。OpenAI 指出，这种做法会让最先进的工具长期远离真正需要它们的用户、开发者、企业和网络防御方。不过，公司也强调，之所以短期内接受这一安排，是出于换取未来更广泛开放路径的现实考量，同时配合特朗普政府围绕网络安全行政命令所构建的评估框架与可复用审查流程。

按照 6 月 2 日特朗普政府签署的最新行政命令，监管部门将为新一代 AI 模型建立上线前的基准测试与评估机制，尤其聚焦网络安全和高风险应用领域。在此之前，同样受美国监管关注的 AI 公司 Anthropic 已被要求下架 Claude Fable 5 与 Mythos 5 相关访问能力，尽管该公司已经自愿接受政府审查并根据反馈加入新的安全“护栏”。这也反映出当前美国在前沿大模型发布上的监管态度正趋于审慎与强干预。

目前，GPT‑5.6 系列模型仅通过 API 与 Codex 向 OpenAI 选定的一批合作伙伴和机构开放，普通用户暂时无法直接在 ChatGPT 中体验。OpenAI 表示，待完成与政府的进一步协商和测试流程后，将在未来数周内推动更大范围的开放，并逐步将 GPT‑5.6 系列整合进现有产品矩阵中。
