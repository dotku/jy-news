WEB 域名的官方注册机构是威瑞信 (Verisign)，作为全球规模最大的域名注册管理机构，威瑞信负责管理 WEB 域名好处是不会存在品牌问题 (例如域名滥用)，然而威瑞信管理的域名注册和续费价格通常都比较高，这对用户来说可能是个问题。

WEB 域名注册已经 10 年但此前存在法律纠纷：

2016 年 7 月，ICANN 举行最后拍卖，威瑞信合作公司 NuDotCo 以 1.35 亿美元中标获得 WEB 域名的运营权，但此后 Altanovo Domains (原 Afilias) 等多方提出异议，经历多次 IRP 等法律程序后 WEB 域名始终未能上线。

存在纠纷的原因主要是威瑞信并未参与竞拍 WEB 域名，而是提前与 NuDotCo 秘密签订代理协议由后者参与竞拍，成功中标后再将域名运营权转让给威瑞信。NuDotCo 既没有向 ICANN 披露代理协议，也没有更新申请材料，其他域名注册机构认为这种行为违反多种合规协议。

不过在 2023 年 6 月，ICANN 董事会裁定 NuDotCo 并未违反规则因此允许继续推进 WEB 域名的注册运营，最终到 2026 年 7 月，所有剩余争议都已经解决 (但细节是保密的，可能是这些域名注册机构相互达成了某些协议)，Altanovo IRP 请求也已经撤回，所以 ICANN 正式完成 WEB 域名的根区委派。

预计下半年开始注册：

威瑞信已经发布新闻稿宣布 WEB 域名完成根区委派，根据威瑞信的计划，该公司计划从 2026 年下半年开始面向注册商渠道开放 WEB 域名注册，包括 Sunrise 期和有限注册期。

根据行业规范，通常新域名上线后会有品牌方率先进行注册避免域名被抢注，例如到时候 Google.web 这样的域名都会被Google率先注册，等品牌方完成注册或放弃注册后，域名注册商再逐渐开放注册。

开放注册后顶级优质域名会以溢价方式进行抢注，例如 a.web 这样的域名可能会以极高的溢价进行注册，不过到时候普通域名应该也会同步开放注册，普通域名不存在溢价，但具体定价暂时还不清楚。
