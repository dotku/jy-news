Neoverse CSS中的CSS全称为Compute Subsystem（计算子系统），属于Arm面向大型云服务商和芯片设计企业推出的半定制方案。客户可以在Arm提供的基础IP框架上，自由配置核心数量、缓存容量、内存系统、I/O接口以及芯片互联结构，从而快速打造符合自身需求的定制处理器。过去几年中，该平台已经被微软Azure、Google云等企业用于服务器处理器开发，也广泛应用于英伟达和英特尔的数据处理单元（DPU）产品之中。

根据Arm公布的信息，Neoverse CSS N4支持从8核到128核的灵活配置，最高频率可达3.8GHz。虽然Arm并未披露不同核心规模下的具体频率表现，但外界普遍认为随着核心数量增加，实际运行频率可能相应下调。

在系统扩展能力方面，该平台不仅支持单芯片128核配置，还可通过多芯粒和多插槽方案进一步扩展规模。平台支持UCIe芯粒互联标准，同时允许合作伙伴使用定制化互联技术构建更大规模计算系统，以满足未来超大规模数据中心和人工智能基础设施需求。

缓存和内存子系统相比上一代产品也获得大幅增强。Neoverse CSS N4单颗芯片最高支持256MB三级缓存，每个核心可配备最高2MB二级缓存，同时内置64KB一级指令缓存和64KB一级数据缓存。内存方面不仅支持DDR5，还首次引入LPDDR6支持，以满足不同应用场景对功耗和带宽的需求。

I/O能力同样得到显著提升。新平台最高支持128条PCIe 7.0或PCIe 6.0通道，并兼容CXL 4.0标准，为高性能存储设备、AI加速器以及高速网络接口提供更大扩展空间。

与前代Neoverse CSS N2相比，新平台几乎实现全面升级。上一代产品最多支持64核、每核1MB二级缓存和64MB三级缓存，并仅支持64条PCIe 5.0及CXL通道。相比之下，Neoverse CSS N4在核心数量、缓存规模、I/O带宽以及内存支持等方面均实现大幅提升。

Arm表示，在128核、3GHz运行频率以及每核2MB二级缓存的配置下，Neoverse CSS N4的单插槽性能可达到Neoverse N3平台的两倍，每瓦性能提升约25%，内存带宽则提升约75%。这些改进主要针对人工智能时代的数据中心需求，尤其是在大规模推理、KV Cache管理、网络处理以及加速器编排等场景下，能够提供更高的计算密度和吞吐能力。

Arm同时强调，Neoverse N系列核心与V系列核心定位有所不同。N系列主要以能效和高密度部署为目标，而V系列则追求极致性能。目前英伟达上一代Grace处理器采用Neoverse V2核心，AWS的Graviton系列以及Google云的Axion项目也都大量采用Neoverse架构。与之相比，N系列更多用于控制平面任务、网络处理以及功耗敏感型计算场景。

除了发布Neoverse CSS N4之外，Arm还同步公布了其AGI CPU项目的最新进展。该产品基于Neoverse V3架构打造，已获得包括甲骨文、字节跳动、Meta、OpenAI、Cloudflare和SAP等企业部署支持。Arm希望通过AGI CPU和Neoverse CSS N4形成双路线布局，一方面为客户提供高度定制化芯片开发平台，另一方面推出面向人工智能时代的参考级服务器处理器方案。

随着生成式AI和智能体应用持续推动数据中心升级，越来越多云服务商开始寻求针对特定工作负载优化的定制芯片。Arm此次推出的Neoverse CSS N4，被视为其进一步扩大数据中心市场份额的重要一步。凭借最高128核规模、LPDDR6支持、PCIe 7.0连接能力以及先进的3纳米制造工艺，该平台有望成为未来数年AI基础设施和云计算处理器的重要基础架构之一。
