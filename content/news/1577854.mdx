鸡肋功能删除也好：

迁移功能测试 1 年并未抵达 Windows 11 正式版，原因很有可能是迁移功能过于鸡肋以至于用户不想使用。说鸡肋是有原因的：Windows 11 迁移功能从来不支持完整将整个系统迁移到新 PC，说是迁移但其实只支持个人相关文件迁移。

例如用户可以迁移个人文件、设置和部分个性化设置，但不能迁移已经安装的应用程序、OneDrive 文件、保存的密码和登录凭证，虽然可以通过 Windows Backup 将整块硬盘数据搬过去，但能做的只是搬文件而不是将软件产生的注册表、设置项、凭证等全部迁移。

因此用户如果希望通过迁移功能完成整机迁移是不可能的，还不如使用第三方软件将整个系统盘打包为镜像再到新电脑上重装系统，蓝点网近期迁移过电脑，不过从未使用过 Windows 11 迁移功能，而是借助第三方软件完成的整机迁移。

现在微软建议使用 OneDrive 迁移文件：

删除迁移功能后微软建议用户使用 Windows 备份与还原功能，将指定文件夹、系统设置和部分账户信息备份到 Microsoft 账户，然后在新电脑上登录相同的微软账户进行数据恢复。

用户也可以使用 OneDrive 备份桌面、文档、图片等文件夹中的文件，然后在新电脑上使用 OneDrive 恢复，但无论是 Windows Backup 还是 OneDrive，都依赖云端备份，所以用户要开 Microsoft 365 订阅，否则存储空间是不够的。
