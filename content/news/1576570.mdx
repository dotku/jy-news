外媒GameSpot发文并不看好Xbox和TCL达成的全新协议，称“合作时机可谓糟糕透顶，就在云游戏时间大幅削减的同时，Xbox却将云游戏功能扩展到了TCL电视上”。此前，Xbox早已和LG电视达成了类似合作，在LG智能电视中引入了Xbox App。

如果你的TCL电视支持Xbox Game Pass，只需订阅Game Pass并配备一个Xbox手柄即可开始畅玩。Xbox Game Pass 还提供丰富的游戏库，注册并登录后即可立即开始游戏。需要注意的是，根据订阅的Game Pass套餐级别，玩家可享受的云游戏时长有限。最经济实惠的Game Pass Essential套餐提供5小时的云游戏时长。Game Pass Premium套餐提供10小时;Game Pass Ultimate套餐则提供15小时。目前尚未公布云游戏充值套餐的价格。

此次消息发布之际，正值Xbox的繁忙时期，其下一款重磅第一方游戏《战争机器：事变日》即将发售。此前，Xbox游戏平台在过去一年中通过其订阅服务推出了75款首发游戏 。此外，更多Game Pass游戏也将在9月陆续上线，其中《极速跑者2：速度之王》和《使命召唤：黑色行动 冷战》将领衔首批新作。

TCL电视通常定位为中低端产品，这可能会让Xbox接触到数百万原本不会购买其昂贵主机的消费者。Xbox用于游戏串流的Azure服务器属于其母公司微软，这些服务器已经开始为微软带来可观的利润。微软最近公布的上一季度Azure服务器销售额为294亿美元，但亚马逊网络服务（AWS）的季度收入仍然高达422亿美元，远超微软。

Xbox官方声明

今天，我们宣布与TCL建立新的合作伙伴关系，未来几个月内，XBOX应用将登陆部分TCL智能电视。

我们希望成为全球玩家游戏的首选平台。这意味着让玩家在游戏方式和地点方面拥有更多选择，让Xbox游戏体验更加便捷。将Xbox应用程序引入部分TCL智能电视，正是朝着这个目标迈出的又一步。我们将携手合作，让Xbox游戏比以往任何时候都更加触手可及，使遍布25个国家/地区的数百万TCL电视用户能够在他们已有的智能电视上畅玩Xbox游戏。

要开始游戏，您需要一台支持的智能电视，并安装Xbox应用;还需要一个支持的控制器。此外，您还需要Xbox Game Pass中包含云游戏时间（也可单独购买）。如果您拥有Game Pass，即可立即畅玩海量云游戏。

在支持的TCL智能电视上，玩家可以通过Xbox应用，利用Game Pass订阅访问Xbox云游戏，直接在电视上畅玩支持的Xbox游戏。符合条件的Xbox Game Pass订阅用户可以通过云端游戏时间，立即访问包含热门大作、经典系列和独立佳作的海量游戏库。

无论您是在支持的TCL智能电视、游戏机还是PC上玩游戏，您的游戏、好友、成就和存档都会随您一起在XBOX生态系统中传输，让您随时随地轻松畅玩。

通过将XBOX应用引入部分TCL智能电视，我们为玩家提供了另一种简单的方式来玩游戏并与游戏社区保持联系。

随着我们不断将Xbox带到更多设备上，像TCL这样的合作伙伴可以帮助我们为玩家提供更大的灵活性，让他们能够以自己喜欢的方式玩自己喜欢的游戏。
