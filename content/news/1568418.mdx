《Ironwood》，一款以机器人为主题的西部生存游戏，受《西部世界》启发

根据GamesBeat报道，在微软裁员之后，这些项目的未来如今变得不确定。

裁员规模与现状

深陷裁员风暴：在本轮Xbox宣布的3200人裁员计划中，位于德克萨斯州的id Software成为重灾区，裁员比例70%。

具体人数：在约185名全职员工中，136人被裁。

受影响部门：裁员波及AI编程、技术设计、渲染、关卡设计、游戏性与战斗设计、游戏引擎开发、环境美术等多个关键团队。其中，工会员工占了被裁人员的约70%，远程办公人员（约35人）也悉数被裁。

幸存部门：仅剩电影剪辑（cinematics）、服务与运维（services and devops）以及游戏性工程（gameplay engineering）等少数部门，引擎团队也仅剩寥寥数人。

裁员背后的原因

处于项目空窗期：工作室刚刚完成并推出了《毁灭战士：黑暗时代》的DLC《启示录》，正处于探索新项目的阶段，因而显得十分脆弱。

单机游戏模式的商业困境：《毁灭战士：黑暗时代》虽然在Metacritic上获得了83分的不俗评价，但由于大量玩家通过Xbox Game Pass免费游玩，导致其独立零售销量疲软。在微软如今更看重营收和利润的背景下，该工作室成为了削减成本的目标。

Xbox Game Pass表现不及预期：报道指出，Xbox Game Pass原本的订阅用户目标是7700万，但目前停留在3000万且处于下滑态势，迫使微软调整整体战略。

被取消或搁置的潜在项目

在裁员发生前，团队正在构思或处于概念阶段的几个项目目前前景不明：

《Fury》（代号）：一款融合了科幻、黑色电影、赛博朋克风格及“枪斗术”的原创IP游戏，风格类似《疾速追杀》，原计划可能面向微软下一代主机Project Helix。

《完美黑暗》（Perfect Dark）新案：在另一家Xbox工作室The Initiative于2025年7月关闭后，id Software曾考虑接手该IP并制作了概念图。

《Ironwood》（代号）：一款西部风格、主打生存的机器人游戏，灵感类似于《西部世界》。

《毁灭战士》多人/合作模式：引入前作经典武器的多人或联机合作内容。

技术与未来的不确定性

自研引擎的危机

id Software一直使用独家的id Tech 8引擎，这是其保持高帧率和画面优势的核心。但微软旗下其他工作室（如Halo Studios）正逐步向虚幻引擎标准化过渡。如果id也放弃自研引擎，将会带来巨大的技术风险。

转型为辅助工作室

目前，部分未被裁减的员工已被派去协助Arkane工作室的《漫威刀锋战士》（Blade）以及MachineGames的《德军总部3》。id Software未来可能会像黑曜石协助《辐射》系列那样，沦为贝塞斯达（Bethesda）其他游戏的“辅助工作室”。

员工士气与业界反思

工作室负责人Marty Stratton在Teams会议上向员工宣布消息时一度哽咽。前创始人John Romero也发推表达了惋惜。前员工表示，这种一刀切的裁员证明了当前3A级游戏生态系统的模式对于开发者而言是不可持续。
