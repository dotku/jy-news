微软在 Visual Studio Code 1.136 版本更新说明中透露了这一消息。纪录片将回顾 VS Code 过去十年的发展历程，讲述它如何从一款发布初期备受欢迎的编辑器，逐步成长为全球开发者广泛使用的工具。微软表示，如果观众曾喜欢五年前推出的六集 Xbox 历史纪录片，那么这部作品或许同样值得期待。目前，官方已经发布了一段约两分钟的预告片。

纪录片还将聚焦 VS Code 对人工智能技术的适应过程。随着 AI 改变软件开发和代码编写方式，VS Code 也在持续加入相关功能。近期的版本更新中，大量改动都与人工智能有关，反映出 AI 已成为该编辑器发展方向的重要组成部分。

影片将通过最初参与开发 VS Code 的创作者，以及后来推动其发展壮大的开发者社区成员的第一手讲述，呈现这款软件从诞生到成长至今的过程。纪录片由 Stefan Kingham 担任导演和制片人。
