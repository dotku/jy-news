结束主流支持后不再提供新功能：

Windows Server 2022 在 10 月份结束主流支持后会自动转为扩展支持，转为扩展支持后微软仍然会按月发布必要的安全更新修复漏洞，因此对于使用该版本的企业来说不必急于升级。不过按照惯例结束主流支持后微软不再向其提供功能更新，即扩展安全更新仅维持必要的安全更新。

Windows Server 2022 发布于 2021 年 3 月，主流支持到 2026 年 10 月结束，而扩展支持则会到 2031 年 10 月 14 日，在扩展支持到期前 IT 管理员可以按照正常流程继续安装和部署必要的安全更新。

微软建议企业升级到 Windows Server 2025：

Windows Server 2022 基于 Windows 10 分支版本开发，之后微软推出 Windows Server 2025 且该版本基于 Windows 11 开发，Windows Server 2025 已经支持无损升级，即企业不必重装系统就可以从旧版本直接升级到 Windows Server 2025。

目前微软正在推荐企业升级到 Windows Server 2025，因为新版本带来更多新功能以及 AI 管理方面的优势。微软建议 IT 管理员提前评估 Windows Server 2025 以便尽早完成迁移，当然升级 Windows Server 2025 并不是免费的，企业需要购买许可证后才能使用 (服务器版都不支持免费升级，每个版本都需要购买许可证)。
