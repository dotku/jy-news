萨蒂亚纳德拉表示，微软将专注于 Windows 系统的基本功能以赢回用户，如此来说微软其实应该从内部数据中知道很多用户不满 Windows 11，退回到 Windows 10 或转投其他操作系统，这或许也是早前微软发布博客宣布对 Windows 11 相关功能和体验进行重大调整的原因。

系统和搜索用户继续增长：

据微软公布的数据，当前 Windows 月活跃用户已经突破 16 亿，而必应搜索的月活跃用户则是突破 10 亿，必应搜索的增长率非常高，这显然和微软在 Windows 11 中捆绑必应搜索有关，因此从这方面来说微软继续利用各种方式吸引用户使用 Microsoft Edge 浏览器的决心也不会发生改变。

但值得注意的是，Windows 月活跃用户不等于 Windows 11 月活跃用户，微软在 2018 年公布的数据显示，约有 15 亿台设备运行 Windows 系统，因此不能直接从现在的 16 亿月活跃用户里推断设备总量，也无法细分 Windows 11 月活跃用户总量。

不过整体来说 Windows 11 的装机量还是在持续增长的，原因在于 Windows 10 已经停止预装，现在新出货的笔记本电脑都预装 Windows 11 系统，随着 Windows 10 设备被逐渐淘汰或升级，Windows 11 的活跃用户也在持续增长中。

将确保系统能在低内存 PC 上流畅运行：

萨蒂亚纳德拉还提到微软将优先考虑 Windows 的基本功能和核心用户群体，而且微软也会确保 Windows 11 能够在内存较低的设备上流畅运行，至少从当前情况来看，这对微软继续提高 Windows 设备总量来说至关重要。

原因主要是当前内存价格太高，以 Windows 以前使用内存的豪横程度来说，8GB 内存运行 Windows 11 可能会非常吃力，但配备 16GB 内存的设备价格又太高，因此行业实际情况倒逼微软优化 Windows 11 以减少内存占用、确保 OEM 合作伙伴可以继续向消费者提供入门级价格的设备。
