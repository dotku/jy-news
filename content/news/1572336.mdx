据悉，“OneDrive 照片”是一款基于 Edge WebView2 技术的轻量级 Web 应用，主要功能在于整合展示本地磁盘与云端中的所有照片。由于其内部关联了 Windows 预装的 OneDrive 同步客户端，只要该客户端在后台运行，哪怕用户完全没有登录微软账户，系统也会在后台偷偷静默下载并安装这款新应用。不仅如此，“OneDrive 照片”在安装后甚至会自动取得用户本地所有文件夹的访问权限，并在 Windows 系统的搜索结果中将优先级排在原版的“微软照片”之前。

更让许多企业用户与 IT 管理员感到不满的是，该软件不仅出现在普通消费级 PC 上，还大规模影响到了通过 Microsoft Intune 统筹管理的 Windows 11 企业版设备。由于这款全新应用与 OneDrive 核心客户端深度结合，并未单独提供标准的程序卸载入口，使得管理员和普通用户根本无法在不完全删除整个 OneDrive 的情况下单独移除它。面对各界提出的安全风险与使用打扰质疑，微软强调，Windows Photos 原有的本地与云端自主选择权依然保留，公司后续将推出更新以修正本次误推送，并为用户恢复单独卸载该应用的能力。
