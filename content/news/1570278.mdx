双路 / 单路服务器以及完整 PCIe 6.0 支持：

此次华硕推出的这些机架式服务器中包含单路和双路版本，例如旗舰级双路服务器 ASUS RS700A/RS720A，这些服务器可以提供极致的计算密度。单路服务器 ASUS RS500A/RS520A，这些服务器可以提供更高的空间利用率和部署灵活性。

华硕强调无论是单路还是双路服务器均支持完整的 PCIe 6.0 协议，这意味着企业可以选购支持该协议的固态硬盘从而获得更高的读写速度。这些服务器还提供卓越的散热管理和运行效率，满足企业级人工智能、虚拟化、存储和云环境的要求。

华硕 RS720A 规格亮点：

外形尺寸：2U

主处理器：2 颗 AMD 威尼斯 SP8 处理器，最高功耗 400W

内存规格：32 个 DDR5 DIMM 插槽，2DPC 最高可达 8000MT / 秒，使用 MRDIMM 最高可达 11200MT / 秒

硬盘数量：取决于不同的 SKU

硬盘可选：32 个 E3.S PCIe 6.0 固态盘

硬盘可选：24 个 2.5 英寸 NVMe 固态盘

硬盘可选：12 个 2.5/3.5 英寸 NVMe 固态盘

扩展槽位：最多 10 个 PCIe 6.0 插槽，包含 6 个 x8 链路或 3 个 x16 链路 FHFL 插槽，2 个 x16 链路 FHFL 插槽

扩展槽位：2 个 OCP 3.0

显卡支持：最多可以安装 3 张双槽 GPU 卡，功耗最高为 450W

主要电源：1+1 冗余 3200W/2700W 80 PLUS 钛金电源

华硕 RS700A 规格亮点：

外形尺寸：1U

主处理器：2 颗 AMD 威尼斯 SP8 处理器，最高功耗 400W

内存规格：32 个 DDR5 DIMM 插槽，2DPC 最高可达 8000MT / 秒，使用 MRDIMM 最高可达 11200MT / 秒

硬盘数量：取决于不同的 SKU

硬盘可选：4 个 2.5/3.5 英寸 NVMe 固态盘

硬盘可选：12 个 2.5 英寸 NVMe 固态盘

硬盘可选：16 个 E3.S PCIe 6.0 固态盘

扩展槽位：最多 4 个 PCIe 6.0 插槽，包含 2 个 PCIe 6.0 x16 链路 FHHL 插槽，另配 2 个 OCP 3.0 插槽

显卡支持：最多可以安装 2 张单槽 GPU 卡，功耗最高为 140W

主要电源：1+1 冗余 2000W 80 PLUS 钛金电源

华硕 RS520A 规格亮点：

外形尺寸：2U

主处理器：1 颗 AMD SP8 处理器，最高功耗 400W

内存规格：16 个 DDR5 DIMM 插槽，2DPC 最高可达 8000MT / 秒，使用 MRDIMM 最高可达 11200MT / 秒

硬盘数量：取决于不同的 SKU

硬盘可选：12 个 3.5/2.5 英寸 NVMe 固态盘 + 4 个 E1.S 中置硬盘位 (部分型号)

硬盘可选：24 个 2.5 英寸 NVMe 固态盘

硬盘可选：16 个 2.5 英寸 NVMe 固态盘 + 8 个 2.5 英寸 SAS 硬盘

扩展槽位：12 盘位或 16 盘位 SKU 提供 1 个 PCIe 6.0 x16 链路 FHFL 插槽

扩展槽位：2 个 PCIe 6.0 x8 链路 FHFL 插槽，2 个 OCP 3.0 插槽

扩展槽位：24 盘位 SKU 提供 1 个 PCIe 6.0 x16 链路 FHFL 插槽、1 个 OCP 3.0 插槽

显卡支持：12 盘位或 16 盘位 SKU 最多可以安装 3 张单槽 GPU 卡

显卡支持：1 张双槽 GPU 卡 + 2 张单槽 GPU 卡，功耗最高为 350W

显卡支持：24 盘位 SKU 最多可以安装 1 张双槽 GPU 卡，功耗最高为 350W

主要电源：1+1 冗余 2700W/2000W 80 PLUS 钛金电源

华硕 RS500A 规格亮点：

外形尺寸：1U

主处理器：1 颗 AMD SP8 处理器，最高功耗 400W

内存规格：16 个 DDR5 DIMM 插槽，2DPC 最高可达 8000MT / 秒，使用 MRDIMM 最高可达 11200MT / 秒

硬盘数量：取决于不同的 SKU

硬盘可选：12 个 2.5 英寸 NVMe 固态盘 + 4 个 E1.S 中置硬盘位 (部分型号) 或 16 个 E3.S 硬盘

扩展槽位：最多 2 个 PCIe 插槽，包含 2 个 PCIe 6.0 x16 链路 FHHL 插槽，另配 2 个 OCP 3.0 插槽

显卡支持：最多可以安装 2 张单槽 GPU 卡，功耗最高为 72W

主要电源：1+1 冗余 2000W 80 PLUS 钛金电源
