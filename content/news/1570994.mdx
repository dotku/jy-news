英特尔的 Atom CPU 产品线基于 x86-64 指令集架构。在以往的业务布局中，英特尔主要将 Atom 处理器应用于入门级产品和低功耗场景，例如网络设备等。随着英特尔业务重心的转移，传统的 Atom CPU 产品线规模已大幅收缩。在全面转向 E-Core（能效核）之前，英特尔设计了上一代 Tremont 微架构，并应用于 Elkhart Lake 和 Jasper Lake 芯片，主要面向嵌入式设备、低功耗笔记本电脑及 Chromebook 等市场。此后，英特尔逐步过度到 Gracemont 等微架构构建的 E-Core 体系，实质上继承了 Atom 核心的生态地位。

尽管目前尚不明确英特尔具体将哪一代 Atom CPU 核心 IP 共享给 Rosaic，但该公司很有可能获得 Tremont 或更新一代的 CPU 技术，以此作为其研发 x86 芯片的起点。与此同时，Rosaic 目前正在寻求筹集约 1000 万美元的资金，用以支持其基于低功耗 x86 设计的芯片开发计划。目前，该公司尚未公开发布具体的预热信息或详细的产品方案。

值得注意的是，英特尔首席执行官陈立武（Lip-Bu Tan）与 Rosaic 的首席执行官系长期合作伙伴及共同投资人，双方曾共同投资过 RISC-V 研发企业 Rivos——该公司专注于开发高性能自定义 RISC-V 处理器，并于去年被 Meta 以约 20 亿美元的价格收购。行业分析认为，英特尔 CEO 如今意在通过技术授权的方式，将英特尔的 x86 IP 推广至更多企业，以防止潜在客户转投其他指令集架构的怀抱。
