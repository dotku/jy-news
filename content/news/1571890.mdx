据知情人士透露，这笔交易价值超过15亿美元，目前正在进行中，具体细节可能会有所变动。

一位知情人士表示，Google正在商讨一项关于Mechanize技术的非独家许可协议，作为交易的一部分。该人士还补充说，Google可能从Mechanize引进的人才将从事模型评估和开发工作。

这些对话凸显了人工智能蓬勃发展的两个现实。编程已成为人工智能最重要、也最赚钱的应用之一，而大型科技公司正在积极探索如何获取保持竞争力所需的人才和技术。

这并非Google首次通过变通方式获取人才和技术。过去几年，Google一直将收购构建成混合交易模式，既包括通过收购式招聘引入人才，也包括通过授权许可等方式获取技术。企业有时会采取这种方式来规避 全面收购所带来的反垄断审查。

去年，在OpenAI试图收购Windsurf之后，Google出手收购了Windsurf的人才并获得了其技术授权。Windsurf的首席执行官Varun Mohan现在领导着Google的Antigravity，这是一个智能体编码平台。

2024年，这家搜索巨头重新聘用了Character AI的联合创始人Noam Shazeer ，并支付了费用获得了这家初创公司人工智能技术的非独家使用权（Shazeer最近离开了公司，加入了OpenAI）。

Google和Mechanize均拒绝通过电子邮件置评。

Mechanize 于去年成立，其使命是实现每项工作的自动化，并拥有一批星光熠熠的投资者，其中包括前 GitHub 首席执行官 Nat Friedman、Stripe 首席执行官 Patrick Collison 和播客主持人 Dwarkesh Patel。

这家初创公司今年早些时候宣布，已完成一轮910万美元的融资，估值达到5亿美元。Mechanize的首席执行官Tamay Besiroglu此前曾联合创办Epoch AI，该公司也专注于人工智能模型的测试。

Mechanize 的技术可以帮助科技公司提高其 AI 模型在编码方面的性能——这是Google一直努力解决的问题，而 OpenAI 和 Anthropic 则分别凭借 Codex 和 Claude Code 吸引了大量开发者客户。

Mechanize 的雄心壮志远不止于编程。“我们目前的重点是软件工程，但我们的长期目标是实现整个经济领域中所有高价值工作的全面自动化。”其网站上写道。
