对此，由Google、Opera 和 Vivaldi 等浏览器厂商支持的行业组织“浏览器选择联盟”（Browser Choice Alliance）发表声明指出，微软利用 Windows 操作系统的市场垄断地位为其自有产品引流，是在不正当削弱自由竞争。该联盟表示，微软的行为限制了用户的自主选择权，破坏了网络自由环境，并使竞争对手在公平创新与市场竞争中处于不利地位。

事实上，科技巨头利用主导产品推广自身生态圈服务并非孤例，正如苹果在其生态体系中推广 Safari 和 iCloud，Google利用 Android 和搜索业务布局广告生态一样。此前，微软曾因在 Windows 系统及第三方浏览器中频繁推送 Bing 广告和 MSN 关联内容而引发过不少争议。不过随着管理层调整，微软首席执行官萨蒂亚·纳德拉近期强调，公司正重新聚焦于 Windows 系统的基础体验与产品质量提升，承诺将优化内存占用、保持界面设计一致性，并减少系统缺陷。

目前，微软已在部分最新系统版本中开始清理界面广告，包括在系统初始设置环节移除推广内容、削减 Windows 搜索中的 Bing 广告，以及简化 Widgets 资讯板块。然而，针对微软是否会彻底调整借由 Windows 推广 Edge 和 Bing 的市场策略，目前各界仍持观望态度。
