Epic 于 10 月 14 日发布了 Epic Games Launcher 的 Linux 预览版，这是该启动器首次面向 Linux 用户推出。虽然《堡垒之夜》目前仍无法在 Linux 上运行，但 Epic 明确表示，希望最终让这款游戏登陆该平台。

《堡垒之夜》此前未能支持 Linux，主要原因在于作弊防控。Epic 的 Easy Anti-Cheat（EAC）反作弊服务本身支持 Linux，但《堡垒之夜》并未启用该平台支持。早在 2022 年 2 月，Epic Games 首席执行官蒂姆·斯威尼就曾表示，公司没有信心在种类繁多的 Linux 内核配置下，大规模、有效地应对作弊问题。

如今，Epic 宣布将重建面向 Linux 的 Easy Anti-Cheat，新版本被称为 EAC Linux v2。Epic 在博客文章中表示，为了将《堡垒之夜》带到 Linux，公司正在重建 EAC，并与各发行版维护者合作制定安全要求。一旦该方案获得足够多发行版维护者的支持，Epic 将通过 Epic Games Launcher 把《堡垒之夜》引入 Linux。Epic 还计划把这些改进开放给其他游戏开发者，帮助他们将自家游戏带给 Linux 玩家。

Epic 表示，EAC Linux v2 将首先在《堡垒之夜》中进行试点。Epic 工程总监里克·戴斯特向 The Verge 表示，公司目前没有确定《堡垒之夜》Linux 版何时能够推出。

此外，Epic 还在研究让《堡垒之夜》兼容 Valve 基于 Linux 的 SteamOS。不过，Epic Games Store 副总裁兼总经理马丁·基利表示，公司并不计划把《堡垒之夜》上架 Valve 的 Steam 商店。Epic 同时指出，Steam Deck 目前不支持 EAC v2 方案所需的必要功能，但公司正在与 Valve 积极沟通，希望未来能够提供支持。
