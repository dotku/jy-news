将从网上商店里删除所有 MV2 扩展程序：

从 2025 年开始Google浏览器新版本就在逐渐限制基于 MV2 协议的扩展程序，这些扩展程序可能无法正常安装和启用，需要通过企业管理策略启用特定的策略后才能使用，而后来相关企业策略也被废弃，以至于用户很难再通过简单的方法启用基于 MV2 的扩展程序。

但这不是全部，现在Google宣布在 2026 年 8 月 31 日将从 Chrome Web Store 里删除所有基于 MV2 协议的扩展程序，到时候用户将无法再通过网上商店下载和安装 MV2 扩展程序 (无论用户使用的Google浏览器是什么版本)。这实际上会影响众多仍然在使用旧版Google浏览器的用户，这些用户不愿意升级就是希望继续使用 MV2 扩展。

用户可能需要备份自己的扩展程序：

如果你仍然依赖或必须使用某些基于 MV2 协议的扩展程序，请尽早使用第三方工具下载这些扩展程序安装包，避免Google将其删除后未来无法再从网上商店下载。部分开发者可能会在扩展程序官网或 GitHub 提供旧版安装包，但很多扩展程序已经停止更新和维护，所以用户自行备份才是最重要的。

备份下载方式也很简单，在 Chrome Web Store 搜索安装这个扩展程序：CRX Extractor/Downloader，安装后在商店里找你需要下载备份的扩展程序，然后点击 CRX 下载器扩展即可下载对应扩展程序的 CRX 安装包，未来如果你需要的话，可以在旧版 Chrome 或其他支持 MV2 的 Chromium 浏览器扩展程序管理页面手动安装 CRX 文件。
