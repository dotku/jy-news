其中，GPT‑5.6 Sol 被定位为旗舰级模型，面向复杂推理、代码开发、科学研究、网络安全及长时间运行的智能体（Agent）任务等高端场景。GPT‑5.6 Terra 则是家族中的“均衡款”，官方表示其整体性能可与 GPT‑5.5 相竞争，同时成本仅为后者的一半左右。GPT‑5.6 Luna 是该系列中体量最小、成本最低的型号，更适合追求高速度与低费用的工作负载。

在 GPT‑5.6 中，OpenAI 引入了全新的“最大推理努力（max reasoning effort）”设定，用户可以在使用 Sol 模型时启用这一选项，以进一步提升复杂推理任务的表现。同时，OpenAI 还推出了新的“ultra 模式”，通过调度多个子智能体协同工作，从而突破单一智能体的能力上限，加速复杂推理工作流程。

官方公布的一系列基准测试结果显示，GPT‑5.6 Sol 在多项面向智能体推理、代码生成与安全分析的专业评测中刷新了业界纪录。在 Agents’ Last Exam 测试中，启用自适应推理的 GPT‑5.6 Sol 得分 53.6，比 Claude Fable 5 高出 13.1 分；即便在中等推理设置下，Sol 仍以约四分之一的估算成本领先 Fable 5 11.4 分。

在 Artificial Analysis Intelligence Index 测试中，启用最大推理努力的 GPT‑5.6 Sol 与 Fable 5 的得分几乎持平，却可以以约一半的估算成本、快 61% 的完成速度完成任务。在 Artificial Analysis Coding Agent Index 中，GPT‑5.6 Sol（最大推理）取得 80 分的成绩，创下新的业界最佳，比 Fable 5 高出 2.8 分，同时在输出 Token 数量、任务用时以及估算成本方面都降至其一半左右甚至更低。

在面向复杂工程和真实代码库工作流的 Terminal‑Bench 2.1 与 DeepSWE v1.1 测试中，GPT‑5.6 Sol 均取得新的业界最佳成绩。在面向智能体浏览任务的 BrowseComp 测试中，GPT‑5.6 Sol 得分 92.2%，再次刷新纪录。在模拟操作系统环境的 OSWorld 2.0 测试中，GPT‑5.6 Sol 得分 62.6%，在使用 85% 更少输出 Token 的情况下，超越了 Opus 4.8。

在安全相关评测方面，GPT‑5.6 Sol 同样展现出显著优势。在 ExploitBench 1 测试中，GPT‑5.6 Sol 得分 73.5%，而在相近输出 Token 预算下，GPT‑5.5 仅为 47.9%。在 ExploitGym 2 测试中，GPT‑5.6 Sol 在两小时时间限制下将 GPT‑5.5 的最高通过率从 15.1% 提升至 24.9%，如果将时间延长至六小时，通过率可进一步提升到 33.7%。在面向证券与安全分析的 SEC‑Bench Pro 测试中，GPT‑5.6 Sol 得分 71.2%，显著高于 GPT‑5.5 的 45.8%，同时延迟表现得到改善。

OpenAI 也公布了 GPT‑5.6 系列的定价。GPT‑5.6 Sol 的费用为每百万输入 Token 5 美元、每百万输出 Token 30 美元；GPT‑5.6 Terra 为每百万输入 Token 2.5 美元、每百万输出 Token 15 美元；GPT‑5.6 Luna 则为每百万输入 Token 1 美元、每百万输出 Token 6 美元。此外，OpenAI 还将通过 Cerebras 提供 GPT‑5.6 Sol 的“快速模式”，最高可实现每秒 750 个 Token 的生成速度。

在可用性方面，OpenAI 表示，GPT‑5.6 将在未来 24 小时内陆续在 ChatGPT、Codex 以及 OpenAI API 中上线。ChatGPT Plus、Pro、Business 和 Enterprise 用户可通过中等及更高推理力度设置来访问 GPT‑5.6 Sol；其中，ChatGPT Pro 和 Enterprise 用户还可以选择专为复杂任务设计的 GPT‑5.6 Sol Pro。

对于 ChatGPT Free 与 Go 用户，OpenAI 将提供 GPT‑5.6 Terra 的访问权限。ChatGPT Plus、Pro、Business 和 Enterprise 用户则可以在 GPT‑5.6 Sol、Terra 与 Luna 三款模型之间自由选择，并为每款模型设定不同的推理努力等级。全新的“max 模式”将向所有在 ChatGPT Work 和 Codex 中使用 GPT‑5.6 的用户开放。

在 ChatGPT Work 产品中，GPT‑5.6 Sol ultra 模式将对 Pro 和 Enterprise 用户开放，以满足更复杂的企业级工作流需求；在 Codex 中，全新的 ultra 模式则面向 Plus 及更高级别订阅计划用户提供。伴随 GPT‑5.6 Sol、Terra 与 Luna 的正式上线，OpenAI 新一代通用模型家族已全面进入企业与开发者部署阶段，围绕推理性能、成本效率以及智能体工作流的竞争也随之进一步升级。
