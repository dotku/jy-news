从开发者分享的演示来看，这台红米手机已经能够进入苹果标志性的 iOS 界面。系统设置中的“关于本机”页面显示，设备型号为 iPhone X，系统版本则是 iOS 16.7.16。

根据 GitHub 项目介绍，开发者将苹果开源的 XNU 内核移植到了 Redmi Note 12 4G 搭载的高通骁龙 685 平台上，同时使用来自 iPhone X 的 iOS 16.7.16 用户态组件，包括 SpringBoard 桌面、系统服务等。

整个项目基于此前 Redmi Note 10 Pro的 iOS 移植成果继续开发，并针对骁龙 685的 CPU 架构、内存管理、显示输出等进行了适配。开发者在10月18日的技术文档中表示，设备已经能够在约 3 分钟内启动至 iOS 锁屏界面。

后续消息还显示，原本无法工作的触摸屏和实体按键也已陆续调通。

目前，相关项目已在 GitHub 开源，名称为 ios-topaz。
