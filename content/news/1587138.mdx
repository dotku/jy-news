新版本引入部分函数应用、只读属性默认值、新的 clamp() 函数、\Time\Duration 类及 SortDirection 枚举，并增加了新的 Polling API。

Polling API 支持高效地同时监测多个流，并根据运行平台采用相应机制，包括 epoll、kqueue、event ports 和 WSAPoll。更多更新细节已在 PHP 官方网站的 PHP 8.6 发布说明中公布。
