How to use Grok Build


X Freeze (@XFreeze)

Grok Build has a really nice way to learn the entire tool without ever leaving the terminal



Just type /tour or /tutorial, and Grok Build walks you through everything step by step



It covers:

• Your first prompt

• Attaching files, images & screenshots

• Navigation

• Slash commands

• Parallel work with Worktrees

• Plan Mode & permissions

• AGENTS.md, memory & themes

• Guides, feedback & best practices



It even makes switching from Claude, Cursor, or Codex easier, with support for carrying over your settings, rules, and skills



Instead of opening a massive documentation page and trying to figure everything out yourself, you can learn Grok Build interactively while actually using it



If you're new to Grok Build, just start with /tour
