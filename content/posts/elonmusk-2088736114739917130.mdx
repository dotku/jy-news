Grok has improved massively


Dan (@KettlebellDan)

Look how much Grok has progressed in just 6 months from Grok 3 to Grok 4.6!



As a quick Saturday morning project I gave Grok Build the link to this previous "𝕏 THE GAME" viral (yet ugly) game



Grok was able to watch the video, quickly reverse engineer the game, and make dramatic improvements



You can play it here (on desktop): 

https://kettlebelldan.com/x_the_game_v2/



Some lessons I learned:



- Grok is extremely token efficient. I was able to iterate on the design many times and still kept the token cost surprisingly low (only a few $ to make this game)



-  Grok is great at working with humans. Instead of just telling it what to do, or on the other extreme having it go off and do something itself, ask for a list of options on how to improve and tell Grok which ones to implement. A true partnership



- Anyone can build things these days with AI, no code knowledge needed
