Grok Build just got another workflow-focused update, bringing smarter controls, improved reliability, and better performance.



Release Notes: v0.2.80 — 2026-07-01



Features:

• Command timeouts can now be configured per session with a foreground-only ceiling.

• Background tasks and TODO lists now survive compaction and remain visible to the model.

• Contextual hints can now be toggled individually for undo, plan mode, and image input.



Bug Fixes:

• Subagent dialogs now reliably show full transcripts on open and reopen.

• Recap blocks now copy only the summary body, not the header label.

• Vim navigation keys now type into dashboard prompts, and modals properly handle Esc/Left.



Performance:

• Network connections are now more resilient to proxy/load balancer drops.

Another major Grok Build update just landed, bringing new features, smarter workflows, performance improvements, and important bug fixes



Release Notes: v0.2.79 — 2026-06-30



Features:

• Contextual hints now surface shortcuts like plan mode and clipboard paste when relevant.

• Graceful shutdowns let interrupted turns resume with a configurable pause budget.

• http://Grok.com chat sessions now fully integrate with the gateway bridge for model catalog and resume.



Bug Fixes:

• Question prompts now time out after 6 minutes instead of blocking indefinitely.

• Fixed a crash that could occur during conversation integrity repairs while a turn was active.



Performance:

• Compaction now performs part of its work in the background before blocking the session, improving responsiveness.
